# 프롬프트 예시

AI에게 보낸 질문과 그 응답을 함께 봅시다.

## 예시1)

```prompt
서울 여행 1박 2일 일정을 추천해줘.
```

```response
DAY 1

경복궁 → 북촌한옥마을 → 익선동 → N서울타워

- 경복궁 : 서울 대표 궁궐 / 한복 체험 / 사진 명소
- 북촌한옥마을 : 한옥 골목 산책 / 감성 카페
- 익선동 : 소품샵 / 한옥 카페 / 디저트 맛집
- N서울타워 : 서울 야경 / 남산 데이트 코스

DAY 2

성수동 → 서울숲 → 롯데월드타워·석촌호수 → 한강공원

- 성수동 : 팝업스토어 / 브런치 카페 / 편집샵
- 서울숲 : 산책 / 휴식 / 감성 사진
- 롯데월드타워 : 전망대 / 쇼핑 / 야경
- 한강공원 : 치킨 + 라면 / 한강 야경
```

## 예시2)

```prompt
간호학과 학생이 사용할 건강관리 앱 아이디어 추천해줘.
```

```response
**1. 실습 생존 건강관리 앱**

병원 실습을 나가는 간호학과 학생들을 위한 앱이에요. 수면 시간, 식사 여부, 물 섭취, 걸음 수, 스트레스 정도를 기록하면 AI가 컨디션을 분석해줘요.

**2. 약 복용 및 건강 루틴 관리 앱**

간호학과 학생들은 약물 관련 지식도 배우니까 전공과 연결하기 좋아요. 복용 중인 약, 영양제, 수면 시간 등을 입력하면 약 복용 알림과 건강 루틴을 관리해주는 앱이에요.

**3. AI 증상 분석 건강 도우미**

사용자가 증상(두통, 피로, 발열 등)을 입력하면 AI가 가능한 원인과 생활 관리 방법을 알려주는 앱이에요. 물론 진단이 아니라 건강관리 가이드 중심으로 구성하는 게 좋아요.
```

응답이 길면 상자가 문단 경계에서 나뉘어 다음 페이지로 이어집니다. 글자 크기는 그대로입니다.
:::
