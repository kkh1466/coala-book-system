# BMI 앱 설계 예시

지금까지 학습한 내용을 활용하여 BMI 건강 체크 앱을 설계해봅시다.

## 입력 데이터 정하기

사용자는 어떤 정보를 입력해야 할까요?

입력 데이터

- 키(cm)
- 몸무게(kg)
- 성별

## 버튼 정하기

사용자가 결과를 확인하기 위해 필요한 버튼은 무엇일까요?

버튼

- BMI 계산하기

## 결과 정하기

앱은 어떤 결과를 보여줄까요?

출력 결과

- BMI 수치
:::

:::page{type="step-process" id="submit-flow"}
# 과제 제출 순서

단계가 여섯 개라 한 페이지에 다 들어가지 않습니다. 넘어간 카드 위에도 화살표가 있어야 하고 번호가 이어져야 합니다.

## 프로젝트 저장하기

**저장** 단추를 눌러 지금까지의 작업을 저장합니다.

## 실행해서 확인하기

1. **실행** 단추를 누릅니다.
2. 오류가 없는지 확인합니다.
3. 창을 닫습니다.

## 파일 이름 확인하기

파일 이름은 **학번_이름.py** 형식이어야 합니다. 띄어쓰기는 쓰지 않습니다.

## 압축하기

프로젝트 폴더를 통째로 압축합니다.

- 폴더 안에 실행 파일이 있어야 합니다.
- 캡처 이미지는 함께 넣지 않아도 됩니다.

## 제출 페이지 열기

수업 페이지의 **과제 제출** 메뉴를 엽니다.

## 파일 올리고 제출 누르기

압축 파일을 올린 뒤 **제출**을 누릅니다. 제출 완료 문구가 뜨면 끝입니다.
:::
