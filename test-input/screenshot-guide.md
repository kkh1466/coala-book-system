# 새 프로젝트 만들기

아래 순서대로 따라 하며 첫 프로젝트를 만들어 봅시다. 단계마다 화면 캡처 자리가 있고, 캡처는 반 너비라 한 페이지에 두 단계씩 놓입니다.

## 프로젝트 만들기 버튼 누르기

첫 화면 오른쪽 위의 **새 프로젝트** 버튼을 누릅니다.

::image{src="assets/guide/step-01-new-project.png" alt="첫 화면의 새 프로젝트 버튼" ratio="16:9" width="half"}

## 프로젝트 이름 정하기

이름 칸에 프로젝트 이름을 적습니다.

- 한글과 영문 모두 쓸 수 있습니다.
- 띄어쓰기 대신 밑줄을 씁니다.

::image{src="assets/guide/step-02-name.png" alt="프로젝트 이름 입력 창" ratio="16:9" width="half"}

## 템플릿 고르기

::image{src="assets/guide/step-03-template.png" alt="템플릿 선택 화면" ratio="16:9" width="half"}

**빈 프로젝트**를 고르고 다음을 누릅니다. 캡처가 지시문보다 위에 와도 됩니다.

## 만들기 완료

**만들기** 버튼을 누르면 새 프로젝트가 열립니다.
