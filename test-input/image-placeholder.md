# 긴 글 다음의 이미지

## 설치 과정

설치 과정은 여러 단계로 나뉩니다. 각 단계에서 화면에 나타나는 안내를 차례대로 따라가면 됩니다. 설치 프로그램을 내려받은 뒤 실행하면 가장 먼저 사용 조건에 동의하는 화면이 나옵니다. 조건을 읽고 동의를 선택한 다음 계속을 누릅니다.

다음으로 설치할 위치를 묻는 화면이 나옵니다. 특별한 이유가 없다면 기본 위치를 그대로 두는 것이 좋습니다. 기본 위치를 바꾸면 이후 단계에서 경로를 직접 입력해야 하는 일이 생길 수 있습니다.

설치할 구성 요소를 고르는 화면에서는 기본 선택을 유지합니다. 추가 구성 요소는 나중에 언제든지 더할 수 있으므로 처음부터 모두 선택할 필요가 없습니다. 선택을 마쳤다면 설치를 눌러 진행합니다.

설치가 진행되는 동안에는 컴퓨터를 끄거나 설치 창을 닫지 않습니다. 설치에는 몇 분이 걸릴 수 있습니다. 진행 표시가 끝까지 채워지면 완료 화면이 나타납니다.

완료 화면에서 마침을 누르면 설치가 끝납니다. 바탕 화면에 새 아이콘이 생겼는지 확인합니다. 아이콘이 보이지 않으면 시작 메뉴에서 프로그램 이름으로 검색해 봅니다.

처음 실행하면 초기 설정을 묻는 창이 나옵니다. 화면 색상과 글꼴 크기는 나중에 바꿀 수 있으므로 지금은 기본값으로 둡니다. 설정을 마치면 시작 화면이 나타납니다.

시작 화면에는 최근에 연 프로젝트 목록과 새 프로젝트를 만드는 단추가 있습니다. 아직 만든 프로젝트가 없으므로 목록은 비어 있습니다. 새 프로젝트 단추를 눌러 첫 프로젝트를 만들어 봅니다.

프로젝트 이름을 정하고 저장 위치를 고릅니다. 이름에는 공백이나 특수 문자를 쓰지 않는 것이 좋습니다. 저장 위치는 찾기 쉬운 폴더로 정해 두면 나중에 파일을 옮기거나 백업할 때 편리합니다.
