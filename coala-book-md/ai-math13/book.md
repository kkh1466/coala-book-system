# 바이브프로젝트2
## 데이터를 모으고 예측하는 앱 만들기

### 학습 목표

- Chart와 Table의 역할을 설명할 수 있다.
- 입력한 값을 표와 산점도에 누적하는 수집기를 만들 수 있다.
- 표 저장을 켜고 다음에 열어도 기록이 남는지 확인할 수 있다.
- 수집한 자료를 내 데이터에서 불러올 수 있다.
- 준비된 데이터를 Table에 표시하고 활용할 수 있다.
- 데이터로 만든 예측 방법을 앱의 입력·출력과 연결할 수 있다.

### 데이터를 모으고 다시 사용해 봅시다

12단원에서는 위젯을 배치하고 동작을 설명하여 앱을 만들었습니다. 이번에는 **그래프를 보여 주는 Chart**와 **표를 보여 주는 Table**을 배웁니다.

먼저 키와 몸무게를 입력하면 표와 산점도에 기록이 쌓이는 데이터 수집기를 만듭니다. 모은 자료는 저장하고, 주피터 노트북에서 다시 불러와 확인합니다.

마지막에는 관심 있는 데이터를 골라 **예측 결과를 알려 주는 AI 앱**을 자유롭게 만듭니다. 준비된 자료를 사용해도 되고, 자신이 모은 자료를 활용해도 됩니다.
:::

# Chart: 앱 안에 그래프 보여 주기

## 어떤 그래프를 넣을까요?

::image{src="assets/chart사용예시.png" alt="Chart 위젯 안에 A, B, O, AB를 가로축으로 하는 막대그래프가 표시되어 있다" ratio="1.069136" width="text" caption="Chart에 막대그래프를 넣은 예시"}

**Chart는 앱 화면 안에 그래프를 보여 주는 위젯**입니다. 산점도, 막대그래프, 꺾은선그래프 등 여러 종류의 그래프를 넣을 수 있습니다.

그림은 막대그래프 예시입니다. 뒤의 키·몸무게 수집기에서는 **산점도**를 사용합니다. 어떤 자료를 어떤 그래프로 보여 줄지는 동작 설명에 적습니다.
:::

:::page{type="concept" id="ch13-table-save" layout="basic"}
# Table: 데이터를 표로 남기기

## 표 저장 스위치 켜기

::image{src="assets/표 저장 토글 버튼 안내.png" alt="디자이너 위쪽의 표 저장 스위치가 보라색 테두리와 화살표로 강조되어 있다. 켜면 표에 넣은 내용이 저장되어 다음에 열 때도 나타난다는 안내가 보인다" ratio="1.671134" width="full" caption="표 저장 스위치의 위치를 확인하고 실제로 켜 주세요"}

**Table은 데이터를 행과 열로 보여 주는 위젯**입니다. 입력한 기록을 한 행씩 추가하거나, 불러온 자료의 열 이름과 값을 확인할 때 사용합니다.

**표 저장** 스위치를 켜고 Table에 자료를 넣으면 다음처럼 사용할 수 있습니다.

- **같은 프로젝트를 다시 열어도** 표의 기록이 남아 있습니다.
- **주피터 노트북의 데이터 → 내 데이터**에서 수집한 데이터셋을 찾아 불러올 수 있습니다.

이번에 자료를 다시 불러오는 곳은 노트북의 **내 데이터**입니다. 그림 위쪽의 **내 저장소** 버튼과 구분하세요.
:::

# 키·몸무게 데이터 수집기 만들기

키와 몸무게를 입력하고 **추가**를 누르면 표에 한 행이 생기고, 산점도에도 점이 쌓이는 앱을 만듭니다. Field 두 개와 Button, Chart, Table을 연결해 봅시다.

새 값을 추가해도 **이전 행과 점은 남아 있어야 합니다.** 모은 자료는 표 저장 기능으로 남기고, 다시 열거나 노트북에서 불러와 사용합니다.

> [!TIP]
> 키는 cm, 몸무게는 kg로 단위를 맞추세요. 한 번 입력한 키·몸무게 한 쌍이 표의 한 행과 산점도의 한 점에 함께 반영되어야 합니다.

- [ ] 키와 몸무게를 입력할 화면을 배치할 수 있다.
- [ ] 같은 기록을 표와 산점도에 누적할 수 있다.
- [ ] 저장한 기록을 다시 열고 확인할 수 있다.
:::

# 수집기의 완성 모습 살펴보기

## 입력한 한 쌍의 값이 기록이 됩니다

::image{src="assets/완성된 프로젝트예시.png" alt="키·몸무게 데이터 수집기 예시. 오른쪽에는 키와 몸무게 입력창 두 개와 추가 버튼이 있고, 왼쪽 위에는 누적 산점도, 아래에는 height_cm과 weight_kg 열의 표가 있다" ratio="1.344985" width="full" caption="입력한 기록을 산점도와 표에 함께 보여 주는 수집기 예시"}

- **추가 버튼**을 누르면 새 기록을 표와 그래프에 넣습니다.
- **Chart**의 가로축은 키, 세로축은 몸무게입니다. **Table**에는 한 쌍의 값을 같은 행에 넣습니다.

그림에서 **height_cm은 키(cm)**, **weight_kg는 몸무게(kg)**입니다. 표에 한글 열 이름을 사용해도 됩니다. 그림의 기록은 참고 예시이며, 직접 입력한 값으로 앱을 확인하세요.

# 표와 산점도에 누적하는 동작 만들기

## 위젯 배치하고 표 저장 켜기

프로젝트 이름은 **키·몸무게 데이터 수집기**, 앱 설명은 **입력한 키와 몸무게를 표와 산점도에 누적하여 기록하는 앱**으로 적어 봅시다.

Field 두 개, Button 하나, Chart 하나, Table 하나를 배치합니다. 버튼에 보일 글자는 **추가**로 정하고, **표 저장**을 켭니다. 각 위젯의 이름은 실제 화면에서 확인하세요.

## 추가 버튼의 클릭 시 이벤트

```flow
Field 2개 | 숫자 읽기
Table | 한 행 추가
Chart | 누적하여 표시
```

이벤트 요청문 예시:

추가 버튼을 누르면 두 Field의 키(cm)와 몸무게(kg)를 숫자로 읽어 Table에 한 행씩 추가하고, Chart에도 가로축 키·세로축 몸무게인 산점도로 누적하여 표시해 줘.

> [!KEY_POINT]
> 산점도 요청에는 **누적하여**를 꼭 넣으세요. 마지막 점 하나만 보이는 것이 아니라 이전 점도 남아 있어야 합니다. Table의 이전 행도 유지합니다.
:::

:::page{type="step-process" id="ch13-collect-data"}
# 실행하고 직접 데이터를 모아 봅시다

키는 cm, 몸무게는 kg로 준비합니다. 연습용 값을 사용했다면 실제로 측정한 자료와 구분해 둡니다.

## 프로젝트 생성하고 실행하기

표 저장을 켰는지 확인합니다. **프로젝트 생성**, **생성된 코드 보기 / 실행**, **실행** 순서로 앱을 실행하세요.

## 한 쌍의 값 추가하기

두 Field에 키와 몸무게를 입력하고 **추가**를 누릅니다. 표에 새 행이 생기고, 같은 위치의 산점도 점이 나타나는지 확인합니다.

## 다른 값으로 다시 추가하기

다른 키·몸무게를 입력하고 다시 추가합니다. 첫 기록과 첫 점이 남아 있나요? 여러 기록을 차례로 넣으며 데이터를 모아 보세요.

같은 값의 점은 겹쳐 보일 수 있으므로, 처음에는 서로 다른 값으로 누적 동작을 확인합니다.
:::

:::page{type="concept" id="ch13-reuse-data" layout="basic"}
# 저장한 자료 다시 불러오기

## 같은 프로젝트 다시 열기

표 저장을 켜고 기록한 뒤 같은 프로젝트를 다시 열어 보세요. 이전 Table의 행과 값이 남아 있는지 확인합니다. 산점도를 다시 그릴 때도 저장된 표의 기록을 사용할 수 있습니다.

## 주피터 노트북에서 내 데이터 확인하기

노트북에서 **데이터 → 내 데이터**를 열고 방금 모은 데이터셋을 찾습니다. 자료를 불러와 셀을 실행한 뒤, 키·몸무게가 제대로 들어 있는지 열 이름과 값을 살펴보세요.

데이터셋 이름은 실제 목록에서 확인합니다. 프로젝트 이름과 꼭 같다고 생각하지 마세요.

## 준비된 자료도 Table에 표시하기

직접 모은 자료나 이미 준비된 자료를 앱의 Table에서 확인할 수도 있습니다. 바이브코딩에서도 사용할 실제 자료를 지정한 뒤, 다음처럼 요청하세요.

[데이터셋 이름]의 데이터를 Table에 불러와 보여 줘. 열 이름과 각 행의 값이 보이게 해 줘.

대괄호 안은 실제 자료 이름으로 바꿉니다. Table의 열과 값이 원래 자료와 같은지 확인하세요. 자료 이름만 적고 끝내지 말고, 앱에서 같은 데이터를 읽었는지 살펴봅니다.
:::

# 나만의 예측 AI 앱 만들기

이번에는 **사용자가 값을 입력하면 예측 결과를 알려 주는 앱**을 자유롭게 만듭니다. 관심 있는 데이터를 고르고, 어떤 정보로 어떤 숫자를 예측할지 정해 봅시다.

준비된 데이터셋을 사용해도 되고, 자신이 만든 수집기로 모은 자료를 사용해도 됩니다. 11단원에서 만든 선형회귀식을 활용하면 시작하기 쉽습니다.

> [!TIP]
> 화면 배치와 함께 실제 예측 계산도 연결하세요. Field로 입력받고 Button을 누르면, 데이터에서 만든 예측 방법으로 계산한 결과가 Text에 보여야 합니다.

- [ ] 주제와 데이터를 직접 고를 수 있다.
- [ ] 입력할 x와 예측할 y에 맞게 화면을 설계할 수 있다.
- [ ] 학습한 방법으로 예측하고 결과를 앱에 표시할 수 있다.
:::

# 무엇을 예측하는 앱을 만들까요?

공부 시간으로 점수를, 키로 몸무게를, 이용 조건으로 이용자 수를 예측하는 앱을 생각해 보세요. 실제로 구할 수 있는 자료로 설명할 수 있는 주제를 골라, 다음 내용을 정합니다.

| 정할 내용 | 생각할 질문 |
|---|---|
| 예측할 내용 | 어떤 숫자를 알려 주는 앱인가요? |
| 사용할 데이터 | 준비된 자료인가요, 직접 모은 자료인가요? |
| 입력할 x | 사용자가 어떤 값을 넣어야 하나요? |
| 예측할 y | 앱이 어떤 값을 계산해서 보여 주나요? |
| 화면 구성 | 입력창, 예측 버튼, 결과를 어디에 놓을까요? |

> [!TIP]
> 필요한 역할에 맞춰 위젯을 고르세요. 입력이 여러 개면 Field도 그에 맞춰 준비합니다. Table은 자료 확인에, Chart는 그래프 표시에 활용할 수 있습니다.
:::

:::page{type="step-process" id="ch13-notebook-to-app"}
# 데이터 분석을 앱으로 연결하기

다음은 주피터 노트북에서 분석한 뒤 바이브코딩에서 앱으로 만드는 방법입니다. 자신의 주제에 맞게 활용해 보세요.

## 노트북에서 예측 방법 만들기

자료를 불러오고 x·y를 고릅니다. 필요한 전처리를 한 뒤 앞 단원에서 배운 방법으로 학습합니다. 만들어진 식과 실제 파라미터 값을 확인하세요.

## 앱 화면 배치하기

바이브코딩에서 입력할 Field, 예측할 Button, 결과를 보여 줄 Text를 배치합니다. 입력 순서와 단위도 정하세요. 필요하면 Chart나 Table을 더합니다.

## 예측 버튼에 계산 연결하기

프로젝트 설명에 실제 예측식과 입력 열, 필요한 전처리 기준을 적습니다. 버튼을 누르면 그 방법으로 계산하여 결과를 보여 주도록 설명합니다.
:::

:::page{type="concept" id="ch13-prediction-event" layout="basic"}
# 학습한 식으로 예측 결과 보여 주기

## 프로젝트 설명에 함께 적을 것

노트북에서 만든 식을 사용할 때에는 앱에서도 같은 방식으로 계산할 수 있도록 다음 내용을 적습니다.

- **실제로 만든 예측식과 파라미터 값**.
- **입력할 열 이름과 순서, 단위**.
- **전처리한 방법과 계산 기준**. 평균이나 최솟값 등을 사용했다면 그 값도 함께 적습니다.

## 예측 버튼의 이벤트 요청문

예측 버튼을 누르면 입력값을 [학습한 전처리 방법]으로 바꾸고, [실제로 만든 예측식]으로 계산해 Text에 결과와 단위를 보여 줘.

대괄호는 자신의 방법과 **학습한 식**으로 바꾸세요. 전처리하지 않았다면 그 부분은 뺍니다.

입력은 **학습할 때 정한 같은 기준**으로 바꿉니다. 평균이나 최솟값을 새로 구하지 않습니다.

> [!KEY_POINT]
> y도 바꾸어 학습했다면 결과를 원래 단위로 되돌려 표시하세요. 같은 입력을 넣었을 때 노트북과 앱의 예측 결과가 맞는지 확인합니다.
:::

:::page{type="practice-checklist" id="ch13-check-ai-app"}
# 완성한 예측 앱 확인하기

앱을 실행해 값을 직접 입력해 봅시다. 입력부터 예측 계산, 결과 표시까지 이어지는지 확인합니다. 다른 값으로도 다시 계산해 보세요.

노트북에서 만든 식을 사용했다면 **같은 입력값**으로 두 결과를 비교합니다. 차이가 있다면 입력 순서, 단위, 전처리 기준을 살펴보세요.

- [ ] 실제로 사용할 데이터를 골랐다.
- [ ] 필요한 입력창과 예측 버튼, 결과 표시 공간이 있다.
- [ ] 버튼을 누르면 학습한 방법으로 예측한다.
- [ ] 같은 입력의 노트북 결과와 앱 결과가 맞는다.
- [ ] 입력 순서와 단위, 전처리 기준이 학습할 때와 같다.
