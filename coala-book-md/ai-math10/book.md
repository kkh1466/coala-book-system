# 데이터 전처리
## 선형회귀에 사용할 데이터 준비하기

### 학습 목표

- 데이터 전처리와 숫자의 범위를 맞추는 이유를 설명할 수 있다.
- 표준화와 정규화의 식을 읽고 변환 결과를 비교할 수 있다.
- 레이블 인코딩과 원핫 인코딩을 구분할 수 있다.
- 상관계수의 부호와 절댓값의 의미를 설명할 수 있다.
- AI-chat으로 숫자의 범위를 맞추고 글자를 숫자로 바꿀 수 있다.
- 숫자로 된 열 사이의 관계를 히트맵으로 확인할 수 있다.

### 실제 데이터를 사용하려면 무엇이 필요할까요?

7~9단원에서는 예측 함수를 만들고, 손실을 계산하고, 경사하강법으로 파라미터를 조정하는 원리를 배웠습니다. 실제 데이터를 학습에 사용하려면 먼저 데이터의 형태를 살펴보고 정리해야 합니다.

데이터를 분석이나 학습에 알맞게 준비하는 작업을 **데이터 전처리**라고 합니다. 이번에는 숫자의 범위를 맞추고, 성별이나 혈액형처럼 글자로 된 값을 숫자로 바꾸는 방법을 배웁니다.

또한 숫자로 된 열 사이의 관계를 살펴보며 예측에 쓸 열을 골라 봅니다. 이러한 준비를 마친 뒤 11단원에서 **선형회귀식 만들기**에 도전합니다.

# 숫자의 범위 맞추기

키와 몸무게는 단위와 숫자의 범위가 다릅니다. **각 열의 숫자를 비슷한 기준으로 맞추면** 경사하강법으로 학습할 때 도움이 됩니다.

## 표준화: 평균과 표준편차를 기준으로

**표준화**는 각 값에서 그 열의 평균을 빼고 표준편차로 나눕니다. 표준편차는 값들이 평균 주변에 얼마나 퍼져 있는지를 나타냅니다.

$$
z=\frac{x-\mu}{\sigma}=\frac{x-\text{평균}}{\text{표준편차}}
$$

x는 원래 값, z는 바꾼 값입니다. 평균과 같으면 0, 평균보다 크면 양수, 작으면 음수가 됩니다. 이렇게 바꾼 값들의 **평균은 약 0, 표준편차는 약 1**이 됩니다.

## 정규화: 최솟값과 최댓값을 기준으로

이번에 배울 **정규화**는 숫자를 **0~1 사이**로 바꾸는 방법입니다. 각 값에서 그 열의 최솟값을 빼고, 최댓값과 최솟값의 차이로 나눕니다.

$$
x_{\mathrm{norm}}=\frac{x-x_{\min}}{x_{\max}-x_{\min}}
$$

계산에 사용한 데이터의 **최솟값은 0, 최댓값은 1**이 되고, 나머지 값은 그 사이에 놓입니다. 두 방법 모두 키는 키끼리, 몸무게는 몸무게끼리 **따로 계산**합니다.

:::page{type="comparison" id="ch10-scaling-example"}
# 같은 값도 기준에 따라 달라져요

설명을 위해 키가 160, 170, 180cm인 학생 세 명을 가정해 봅시다. 실제 실습 데이터의 값은 아닙니다. 평균은 170, 표준편차는 약 8.165입니다.

표준화하면 평균인 170이 0이 됩니다. 정규화하면 가장 작은 160은 0, 가장 큰 180은 1, 그 중간인 170은 0.5가 됩니다.

표준화한 값은 음수가 될 수도 있고 1보다 클 수도 있습니다. 정규화와 달리 범위를 0~1로 정하는 방법은 아닙니다.

| 원래 키(cm) | 표준화한 값 | 정규화한 값 |
|---|---|---|
| 160 | 약 −1.225 | 0 |
| 170 | 0 | 0.5 |
| 180 | 약 +1.225 | 1 |

> [!KEY_POINT]
> 숫자를 바꿔도 한 열 안에서 크고 작은 순서는 그대로입니다. 나중에 새 데이터로 예측할 때도 처음에 구한 평균·표준편차 또는 최솟값·최댓값을 그대로 사용합니다.
:::

# 숫자의 범위가 다르면 학습도 달라져요

## 그림으로 학습 과정 비교하기

::image{src="assets/feature-scaling-comparison.png" alt="숫자의 범위를 맞추기 전에는 길쭉한 곡선 안에서 빨간 화살표가 지그재그로 이동하고, 표준화한 뒤에는 둥근 곡선의 중심으로 접근한다. 각 조건에 맞는 학습률을 사용한 설명용 예시로 반복 횟수는 59회와 7회이다" ratio="9:5" width="full" caption="빨간 화살표를 따라 학습이 진행되는 모습을 비교해 봅시다"}

두 축은 **파라미터의 값**입니다. 색깔 있는 선은 손실이 같은 위치를 연결하고, 별표는 손실이 가장 작은 곳을 나타냅니다. 빨간 화살표는 학습이 진행되는 순서입니다.

- **범위를 맞추기 전**: 한쪽 방향으로 크게 흔들리며 지그재그로 이동합니다. 학습이 불안정해지거나 더 많이 반복해야 할 수 있습니다.
- **범위를 맞춘 후**: 중심으로 더 곧게 다가갑니다. 알맞은 학습률을 함께 쓰면 더 안정적으로, 적은 반복으로 학습할 수 있습니다.

이 그림은 **같은 예측에서 시작하되, 학습률은 조건에 맞게 다르게 정한 예시**입니다. 실제 학생 데이터의 결과는 아니며, 항상 그림과 똑같이 빨라지는 것은 아닙니다.

숫자의 범위가 크다고 더 중요한 열은 아닙니다.
:::

# 키와 몸무게의 숫자 범위 맞추기

학생 신체 정보 데이터의 키와 몸무게를 각각 표준화하고 0~1로 정규화해 봅시다. AI-chat으로 코드를 만들고 실행한 뒤, 같은 학생의 원래 값과 바꾼 값을 비교합니다.

표준화한 값에는 음수가 나타나는지, 정규화한 값은 0~1 사이에 놓이는지 살펴봅시다. 두 방법의 차이를 자기 말로 설명해 봅시다.

> [!TIP]
> 원본을 남겨 두고 복사한 표에서 비교하세요. 표준화와 정규화는 각각 원래 열에서 따로 시작합니다. 표준화한 값을 다시 정규화하는 실습이 아닙니다.

- [ ] 키와 몸무게를 각각 표준화하고 정규화할 수 있다.
- [ ] 같은 학생의 원래 값과 변환한 값을 비교할 수 있다.
- [ ] 두 방법으로 바꾼 숫자에 어떤 차이가 있는지 설명할 수 있다.
:::

# AI-chat으로 변환하고 비교하기

## 학생 데이터 불러오기

**데이터 → 교육·학생 → 학생 신체 정보 데이터(결측x) → 불러오기** 순서로 선택하고, 데이터 불러오기 셀을 실행합니다. 준비된 표 df에는 성별, 키, 몸무게, 혈액형 열이 있습니다.

## AI-chat 예시 요청문

불러온 데이터의 키와 몸무게를 각각 표준화하고 0~1로 정규화해 줘. 원본은 남겨 두고, 원래 값과 바꾼 값을 표로 비교해 줘.

AI-chat이 만든 코드를 셀에서 실행합니다. 같은 학생의 값이 어떻게 바뀌었는지 표에서 비교하세요.

## 결과에서 확인할 내용

- 표준화한 값에 음수와 양수가 함께 나타나나요?
- 표준화한 값이 음수이면 원래 값은 평균보다 큰가요, 작은가요?
- 정규화한 값은 **0과 1 사이**에 있나요?
- 같은 학생끼리 비교할 때 값이 크고 작은 순서는 유지되나요?

:::page{type="comparison" id="ch10-label-encoding"}
# 글자로 된 값을 숫자로 바꾸기

우리가 만들 선형회귀 모델은 숫자로 계산합니다. ‘남자’, ‘여자’처럼 글자로 된 값을 숫자로 바꾸는 작업을 인코딩이라고 합니다.

종류가 두 개이면 양성=1, 음성=0처럼 바꿀 수 있습니다. 성별도 0과 1로 표현할 수 있습니다. 어떤 값을 0과 1로 정했는지 기억하고 계속 같은 기준을 씁니다. 숫자가 크다고 더 좋은 것은 아닙니다.

레이블 인코딩은 종류마다 숫자 하나를 붙이는 방법입니다. 낮음·중간·높음처럼 순서가 있다면 다음과 같이 바꿀 수 있습니다.

| 원래 값 | 바꾼 숫자 |
|---|---|
| low: 낮음 | 0 |
| medium: 중간 | 1 |
| high: 높음 | 2 |

> [!KEY_POINT]
> 0, 1, 2는 낮음·중간·높음의 순서를 나타냅니다. 실제 차이가 모두 같은 크기라는 뜻은 아닙니다. 종류가 세 개 이상일 때에는 값 사이에 순서가 있는지 먼저 생각하세요.
:::

:::page{type="concept" id="ch10-onehot" layout="basic"}
# 순서 없는 값은 원핫 인코딩으로

혈액형을 **A=0, B=1, O=2, AB=3**으로 바꾸면 숫자 때문에 크고 작은 순서가 있는 것처럼 계산됩니다. 혈액형에는 이런 순서가 없으므로 다른 방법이 필요합니다.

## 원핫 벡터: 해당하는 자리만 1

숫자를 순서대로 나열한 묶음을 **벡터**라고 합니다. 자기 자리는 1, 나머지는 0으로 쓰면 **원핫 벡터**입니다. A, B, O 순서에서 O를 봅시다.

$$
\mathrm{O}\ \longrightarrow\ [0,\ 0,\ 1]
$$

## 하나의 열을 여러 0·1 열로 나누기

::image{src="assets/원핫인코딩변환예시.png" alt="혈액형 한 열의 O, A, B, O를 혈액형_A, 혈액형_B, 혈액형_O의 세 열로 바꾼 예시. 각 행에서 해당 혈액형만 1이고 나머지는 0이다" ratio="2.904977" width="full" caption="그림은 A, B, O 세 가지 혈액형을 표현한 예시입니다"}

- 첫 번째 O는 **0·0·1**, 두 번째 A는 **1·0·0**으로 바뀝니다.
- 혈액형마다 열을 따로 만들어 0과 1로 표시하는 것이 **원핫 인코딩**입니다. 혈액형 사이에 크고 작은 순서를 만들지 않습니다.
- **행의 수는 그대로이고 열의 수가 늘어납니다.** 실제 학생 데이터에 AB까지 있으면 혈액형_AB 열도 필요합니다.
:::

# 성별과 혈액형을 숫자로 바꾸기

같은 학생 신체 정보 데이터에서 성별과 혈액형을 숫자로 바꿔 봅시다. 어떤 값이 들어 있는지 확인하고, 두 열에 레이블 인코딩과 원핫 인코딩을 각각 적용해 비교합니다.

앞 실습에서 바꾼 키와 몸무게도 다시 살펴봅니다. 원래 값과 어떤 점이 달라졌는지 확인한 뒤, 기존 결과는 남겨 두고 성별과 혈액형을 바꿉니다.

> [!TIP]
> 혈액형에 번호를 붙여 보는 것은 두 방법을 비교하기 위해서입니다. 실제 선형회귀에 혈액형을 넣을 때는 원핫 인코딩을 사용하세요.

- [ ] 성별과 혈액형에 어떤 값들이 들어 있는지 확인할 수 있다.
- [ ] 두 방법으로 바꾼 숫자와 새 열 이름을 비교할 수 있다.
- [ ] 행의 수와 숫자의 의미가 어떻게 달라지는지 설명할 수 있다.
:::

- 원핫 인코딩에서 생긴 열의 이름과 개수는 무엇인가요?

- 인코딩한 뒤에도 학생 수는 그대로인가요?

# 상관계수는 방향과 강도를 나타내요

## 점들이 모이는 방향 살펴보기

::image{src="assets/상관계수이미지.png" alt="r이 +1에 가까운 양의 상관관계, 0에 가까워 뚜렷한 선형 관계가 약한 경우, -1에 가까운 음의 상관관계를 산점도로 비교한 그림" ratio="2.342169" width="full" caption="개념을 설명하는 예시이며 실제 데이터의 분석 결과는 아닙니다"}

**상관계수 r**는 숫자로 된 두 항목의 점들이 직선 주변에 모이는 정도를 **−1에서 +1 사이**로 나타냅니다.

- **+1에 가까움**: 한 값이 커질수록 다른 값도 대체로 커집니다.
- **0에 가까움**: 뚜렷한 직선 방향으로 모이는 정도가 약합니다.
- **−1에 가까움**: 한 값이 커질수록 다른 값은 대체로 작아집니다.

**부호는 함께 커지는지, 반대로 움직이는지**를 알려 줍니다. **절댓값이 1에 가까울수록 직선 주변에 잘 모입니다.** r=−0.9는 r=+0.3보다 강한 관계입니다.

> [!KEY_POINT]
> 0에 가까워도 곡선 모양의 관계는 있을 수 있습니다. 함께 변한다고 한쪽이 다른 쪽의 원인인 것은 아닙니다.
:::

:::page{type="concept" id="ch10-heatmap" layout="basic"}
# 히트맵은 숫자를 색으로 보여 줘요

## 표의 값과 패턴을 한눈에 보기

::image{src="assets/히트맵이미지.png" alt="여러 칸의 값을 숫자와 색으로 나타낸 일반적인 히트맵. 가로축과 세로축에는 0부터 9까지의 번호가 있고 옆에는 색상표가 있다" ratio="7:6" width="text" caption="히트맵 모양을 보여 주는 예시이며 Spotify 실습 결과가 아닙니다"}

**히트맵**은 표의 숫자를 색으로 보여 주는 그래프입니다. 어떤 값이 크고 작은지 한눈에 비교할 수 있습니다. 각 칸의 숫자와 옆의 **색상표**를 함께 읽어 보세요.

위 그림은 히트맵이 어떻게 생겼는지 보여 주는 예시입니다. 다음 실습에서는 **숫자로 된 열 사이의 상관계수**를 구하고, 그 결과를 히트맵으로 나타냅니다.
:::

# 히트맵으로 예측에 쓸 열 살펴보기

숫자로 된 열이 많을 때 상관계수를 히트맵으로 나타내면 **여러 열 사이의 관계를 한 번에 비교**할 수 있습니다. 예측에 어떤 열을 쓸지 살펴볼 때 유용합니다.

## 행과 열의 이름으로 칸 읽기

- 가로축과 세로축에 같은 열 이름들이 놓입니다.
- 한 칸은 가로축 열과 세로축 열 사이의 상관계수입니다.
- 같은 열끼리 만나는 칸의 값은 1입니다. 값이 모두 같은 열은 계산할 수 없습니다.
- 키와 몸무게를 비교한 값은 몸무게와 키를 비교한 값과 같습니다.
- 각 칸의 숫자와 색상표를 함께 읽어 관계를 비교합니다.

## 선형회귀에 쓸 열 고르기

- 예측할 y와 **상관계수가 +1이나 −1에 가까운 열**을 먼저 살펴보세요. 반대로 움직이는 관계도 예측에 도움이 될 수 있습니다.
- 관계가 강한 열을 많이 넣는다고 항상 더 잘 맞히지는 않습니다. 비슷한 정보가 겹칠 수도 있으므로 실제 예측 결과도 확인해야 합니다.
- 학생 번호처럼 숫자로 쓰였어도 예측에 도움이 되지 않는 열이 있을 수 있습니다.
:::

# Spotify 인기곡의 상관관계 보기

이번에는 Spotify 인기곡 데이터로 바꾸어 봅시다. 어떤 열이 숫자로 되어 있는지 확인하고, 그 열들 사이의 상관계수를 구합니다.

AI-chat에 히트맵을 그려 달라고 요청하고 실행합니다. 두 값이 함께 커지는지, 반대로 움직이는지, 뚜렷한 관계가 없는지 살펴봅시다.

> [!TIP]
> 같은 열끼리 비교한 칸은 건너뛰고 다른 열 사이의 관계를 보세요. 음수인 값이 없다면 없다고 기록합니다. 비어 있는 칸은 계산하지 못한 것이며, 상관계수 0과는 다릅니다.

- [ ] Spotify 데이터에서 숫자로 된 열을 확인할 수 있다.
- [ ] 상관계수를 표시한 히트맵을 만들 수 있다.
- [ ] 부호와 절댓값으로 열 사이의 관계를 설명할 수 있다.
:::

# 실제 상관계수 히트맵 만들기

## Spotify 데이터 불러오기

**데이터 → 음악 → Spotify 인기곡 데이터**를 불러오고 실행합니다. df의 열이 음악 데이터로 바뀌었는지 확인하세요.

## AI-chat 예시 요청문

불러온 데이터에서 숫자로 된 모든 열의 상관계수를 구하고, 값을 표시한 히트맵으로 그려 줘.

코드를 실행해 표와 그래프를 확인하세요. 글자가 겹치면 **그림 크기를 늘려 달라고 요청**합니다.

## 결과에서 확인할 내용

- 같은 열끼리 만나는 칸의 값은 1인가요?
- 서로 다른 열 중 +1에 가까운 관계는 무엇인가요?
- −1에 가깝거나 0에 가까운 관계도 있나요?
- 예측할 y를 정한다면 어떤 열을 함께 살펴보고 싶나요?
:::
