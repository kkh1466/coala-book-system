# 오차 기반 학습
## 틀린 만큼 고치며 배우는 기계

### 학습 목표

- 머신러닝 모델이 오차를 이용해 학습한다는 뜻을 설명할 수 있다.
- 오차 기반 학습의 다섯 단계를 순서대로 말할 수 있다.
- 회귀 문제와 분류 문제를 구분할 수 있다.

### 기계는 어떻게 배울까?

처음 다트를 던지면 과녁에서 한참 빗나갑니다. 하지만 얼마나, 어느 쪽으로 빗나갔는지 보고 다음에 조금씩 고쳐 던지면 점점 가운데에 가까워집니다.

머신러닝 모델도 똑같이 배웁니다. 먼저 **예측**하고, 정답과 비교해 **얼마나 틀렸는지** 재고, 그만큼 **고칩니다**. 이렇게 틀린 정도, 즉 **오차**를 줄이는 방향으로 배우는 방식을 **오차 기반 학습**이라고 합니다.

::image{src="assets/ch01/dart-analogy.png" alt="다트가 여러 번 던질수록 과녁 중앙에 가까워지는 모습을 1회, 2회, 3회로 나란히 보여 주는 그림" ratio="16:9"}
:::

:::page{type="concept" id="ch01-error" layout="basic"}
# 오차란 무엇일까?

## 예측과 정답의 차이

**오차**(error)는 모델의 예측값과 실제 정답의 차이입니다. 이 책에서는 오차를 다음과 같이 계산합니다.

**오차 = 예측값 - 실제값**

- 오차가 양수이면 실제보다 크게 예측한 것입니다.
- 오차가 음수이면 실제보다 작게 예측한 것입니다.
- 오차가 0이면 정확히 맞힌 것입니다.

## 코드로 오차 계산하기

학생 세 명의 시험 점수를 예측한 결과와 실제 점수를 비교해 봅시다.

```python
actual = [60, 75, 90]      # 실제 점수
predicted = [55, 80, 90]   # 모델의 예측

for p, a in zip(predicted, actual):
    print("예측", p, "실제", a, "오차", p - a)
```

```output
예측 55 실제 60 오차 -5
예측 80 실제 75 오차 5
예측 90 실제 90 오차 0
```
:::

# 그래프로 보는 오차

## 점과 선 사이의 거리

데이터를 점으로, 모델의 예측을 직선으로 그리면 오차가 눈에 보입니다. 각 점에서 직선까지 세로로 그은 선분의 길이가 바로 그 데이터의 오차입니다.

::image{src="assets/ch01/residual-lines.png" alt="산점도 위에 예측 직선이 있고, 각 점에서 직선까지 세로 점선으로 오차를 표시한 그래프" ratio="4:3" caption="그림 1-1 데이터와 예측 직선 사이의 오차"}

- 점이 직선보다 아래에 있으면 크게 예측한 것이므로 오차가 양수입니다.
- 점이 직선보다 위에 있으면 작게 예측한 것이므로 오차가 음수입니다.
- 선분이 짧을수록 예측이 정확합니다.
- 학습은 이 선분들이 전체적으로 짧아지도록 직선을 옮기는 과정입니다.
:::

# 오차 기반 학습의 네 가지 재료

오차 기반 머신러닝은 어떤 모델이든 다음 네 가지로 이루어집니다.

## 데이터

- 입력과 정답의 쌍
- 예: 공부 시간과 점수

## 모델

- 입력으로 예측을 만드는 식
- 조절할 수 있는 숫자인 **파라미터**를 가짐

## 손실함수

- 오차를 숫자 하나로 요약
- 작을수록 좋은 모델

## 경사하강법

- 손실을 줄이는 쪽으로 파라미터를 조금씩 수정

> [!KEY_POINT]
> 선형 회귀와 로지스틱 회귀는 **모델**과 **손실함수**만 다르고, 나머지 재료와 학습 순서는 같습니다.
:::

:::page{type="step-process" id="ch01-steps"}
# 오차 기반 학습의 순서

이 순서는 이 책에서 배우는 두 모델에 똑같이 적용됩니다.

## 파라미터 초깃값 정하기

모델의 파라미터를 0이나 임의의 작은 값으로 정합니다. 처음에는 엉터리 예측을 해도 괜찮습니다.

## 예측하기

지금의 파라미터로 모든 데이터의 예측값을 계산합니다.

## 손실 계산하기

예측값과 정답의 오차를 구하고, 손실함수로 오차 전체를 숫자 하나로 요약합니다.

## 기울기 구하기

파라미터를 어느 쪽으로 움직여야 손실이 줄어드는지 기울기로 알아냅니다.

## 파라미터 수정하기

기울기의 반대 방향으로 파라미터를 조금 옮깁니다. 그리고 손실이 충분히 작아질 때까지 예측하기부터 다시 반복합니다.
:::

:::page{type="concept" id="ch01-loop" layout="basic"}
# 한 바퀴씩 반복하는 학습

## 학습의 한 바퀴

```flow
예측 | 모델 계산
오차 | 예측 - 정답
손실 | 손실함수
수정 | 경사하강법
```

위의 네 과정을 한 번 거치는 것을 학습의 한 바퀴라고 합니다. 모든 데이터를 한 번씩 사용해 한 바퀴를 도는 것을 **에포크**(epoch)라고 부릅니다.

- 한 바퀴를 돌 때마다 파라미터가 조금씩 바뀝니다.
- 바퀴를 거듭할수록 손실이 줄어듭니다.
- 손실이 더 이상 크게 줄지 않으면 학습을 멈춥니다.

:::

# 회귀와 분류

오차 기반 학습으로 푸는 문제는 정답의 모양에 따라 크게 두 가지로 나뉩니다.

| 구분 | 회귀 | 분류 |
|---|---|---|
| 정답의 모양 | 연속된 숫자 | 정해진 범주 |
| 예 | 공부 시간으로 점수 예측 | 공부 시간으로 합격 여부 예측 |
| 이 책의 모델 | 선형 회귀 | 로지스틱 회귀 |

> [!TIP]
> 이름에 "회귀"가 들어 있지만 **로지스틱 회귀**는 분류 모델입니다. 이름보다 정답의 모양을 보고 판단하세요.

:::page{type="chapter-opening" id="ch02" chapter="2"}
# 손실함수
## 오차를 숫자 하나로 요약하기

### 학습 목표

- 오차를 그대로 더하면 안 되는 이유를 설명할 수 있다.
- 평균제곱오차(MSE)를 계산할 수 있다.
- MAE와 MSE가 큰 오차를 다루는 방식의 차이를 설명할 수 있다.

### 왜 숫자 하나가 필요할까?

데이터가 100개라면 오차도 100개입니다. 모델 A와 모델 B 중 어느 쪽이 더 좋은지 비교하려면 오차 100개를 **숫자 하나**로 줄여야 합니다.

이렇게 모델이 얼마나 틀렸는지를 숫자 하나로 나타내는 함수를 **손실함수**(loss function)라고 합니다. 손실이 작을수록 좋은 모델이고, 학습의 목표는 손실을 가장 작게 만드는 파라미터를 찾는 것입니다.
:::

:::page{type="concept" id="ch02-sum-problem" layout="basic"}
# 오차를 그냥 더하면?

## 양수와 음수가 서로 지운다

1장의 예에서 오차는 -5, 5, 0이었습니다. 이 오차를 그대로 더해 봅시다.

```python
errors = [-5, 5, 0]

print("오차의 합:", sum(errors))
```

```output
오차의 합: 0
```

두 학생의 점수를 5점씩 틀렸는데도 합이 0이 되어, 완벽한 모델처럼 보입니다. 크게 빗나간 예측이 반대 방향의 예측과 만나면 서로 지워지기 때문입니다.

> [!KEY_POINT]
> 손실함수는 오차의 **방향**이 아니라 **크기**를 모아야 합니다. 그래서 오차를 제곱하거나 절댓값을 씌운 뒤 더합니다.
:::

:::page{type="concept" id="ch02-mse" layout="basic"}
# 평균제곱오차(MSE)

## 제곱해서 평균 내기

**평균제곱오차**(Mean Squared Error, MSE)는 오차를 모두 제곱한 뒤 평균을 낸 값입니다. 선형 회귀에서 가장 많이 쓰는 손실함수입니다.

**MSE = (각 오차를 제곱한 값의 합) ÷ 데이터 개수**

- 제곱하면 음수 오차도 양수가 되어 서로 지워지지 않습니다.
- 오차가 0일 때만 MSE도 0이 됩니다.

## 코드로 MSE 계산하기

```python
errors = [-5, 5, 0]

squared = [e ** 2 for e in errors]
mse = sum(squared) / len(squared)
print("제곱한 오차:", squared)
print("MSE:", round(mse, 2))
```

```output
제곱한 오차: [25, 25, 0]
MSE: 16.67
```
:::

:::page{type="concept" id="ch02-mae-vs-mse" layout="basic"}
# 큰 오차에 더 민감한 MSE

## 크게 틀린 예측이 하나 있을 때

오차에 절댓값을 씌워 평균 낸 값을 **평균절대오차**(MAE)라고 합니다. 오차 네 개 중 하나만 크게 틀렸을 때 두 값을 비교해 봅시다.

```python
errors = [1, -1, 2, -10]   # 마지막은 크게 틀린 예측

mae = sum(abs(e) for e in errors) / len(errors)
mse = sum(e ** 2 for e in errors) / len(errors)
print("MAE:", mae)
print("MSE:", mse)
```

```output
MAE: 3.5
MSE: 26.5
```

오차 -10은 제곱하면 100이 되어 MSE 전체를 크게 끌어올립니다. MSE로 학습하면 모델은 크게 틀린 데이터를 먼저 고치려고 합니다.
:::

:::page{type="comparison" id="ch02-mae-mse-table"}
# MAE와 MSE 비교

두 손실함수 모두 오차의 크기를 모으지만, 성질이 조금 다릅니다.

| 구분 | MAE | MSE |
|---|---|---|
| 계산 | 오차의 절댓값 평균 | 오차의 제곱 평균 |
| 큰 오차 | 크기만큼만 반영 | 제곱으로 크게 반영 |
| 그래프 모양 | 뾰족한 V자 | 매끄러운 U자 |
| 기울기 계산 | 0에서 뾰족해 불편 | 어디서나 매끄러워 쉬움 |

> [!TIP]
> 기울기를 구하기 쉽다는 점 때문에 경사하강법과 함께 쓸 때는 MSE를 많이 씁니다. 다음 장에서 그 이유를 확인합니다.
:::

:::page{type="concept" id="ch02-loss-shape" layout="basic"}
# 손실함수의 모양

## 파라미터에 따라 달라지는 손실

같은 데이터라도 모델의 파라미터를 바꾸면 예측이 바뀌고, 따라서 손실도 바뀝니다. 파라미터 하나를 가로축, 손실을 세로축으로 그리면 MSE는 매끄러운 **U자 곡선**이 됩니다.

::image{src="assets/ch02/loss-u-curve.png" alt="가로축이 가중치 w, 세로축이 MSE인 U자 곡선이며 가장 낮은 점에 최솟값 표시가 있는 그래프" ratio="16:9" caption="그림 2-1 가중치 w에 따른 MSE"}

- 곡선의 가장 낮은 점이 손실이 가장 작은 파라미터입니다.
- 학습은 이 가장 낮은 점을 찾아가는 과정입니다.
- 가장 낮은 점을 찾는 방법이 바로 다음 장의 **경사하강법**입니다.
:::

:::page{type="chapter-opening" id="ch03" chapter="3"}
# 경사하강법
## 손실의 골짜기를 따라 내려가기

### 학습 목표

- 기울기가 파라미터를 움직일 방향을 알려 준다는 것을 설명할 수 있다.
- 경사하강법의 수정 규칙으로 파라미터를 한 걸음 옮길 수 있다.
- 학습률이 너무 작거나 클 때 생기는 문제를 설명할 수 있다.

### 안개 낀 산에서 내려오기

짙은 안개 때문에 앞이 보이지 않는 산에서 가장 낮은 골짜기로 내려가야 한다고 생각해 봅시다. 멀리는 보이지 않지만 발밑의 땅이 어느 쪽으로 기울었는지는 느낄 수 있습니다.

가장 쉬운 방법은 **내리막 쪽으로 한 걸음** 내딛고, 다시 발밑을 확인해 또 한 걸음 내딛는 것입니다. 이것이 **경사하강법**(gradient descent)의 생각입니다. 산은 손실함수, 내 위치는 파라미터, 발밑의 경사는 기울기입니다.
:::

:::page{type="concept" id="ch03-gradient" layout="basic"}
# 기울기가 알려 주는 것

## 접선의 기울기

곡선 위 한 점에서 곡선에 살짝 닿는 직선을 **접선**이라고 합니다. 접선의 기울기는 그 점에서 파라미터를 조금 늘렸을 때 손실이 얼마나, 어느 쪽으로 변하는지를 알려 줍니다. 이 값을 미분으로 구합니다.

::image{src="assets/ch03/tangent-slopes.png" alt="U자 손실 곡선 위 두 점에 접선을 그린 그래프. 최솟값 왼쪽 점의 접선은 오른쪽 아래로, 오른쪽 점의 접선은 오른쪽 위로 기울어 있다" ratio="16:9" caption="그림 3-1 위치에 따라 달라지는 접선의 기울기"}

- 기울기가 양수이면 오른쪽이 오르막이므로 w를 **줄여야** 합니다.
- 기울기가 음수이면 오른쪽이 내리막이므로 w를 **늘려야** 합니다.
- 기울기가 0에 가까우면 골짜기 바닥에 거의 도착한 것입니다.
:::

:::page{type="concept" id="ch03-update-rule" layout="basic"}
# 경사하강법의 수정 규칙

## 기울기의 반대 방향으로 한 걸음

앞의 세 가지 경우는 규칙 하나로 정리됩니다.

**새 파라미터 = 지금 파라미터 - 학습률 × 기울기**

- 기울기 앞의 빼기 때문에 항상 기울기의 **반대 방향**으로 움직입니다.
- **학습률**(learning rate)은 한 걸음의 크기를 정하는 숫자로, 사람이 미리 정합니다.
- 기울기가 클수록 한 번에 많이 움직이고, 바닥에 가까워질수록 조금씩 움직입니다.

> [!KEY_POINT]
> 경사하강법은 모델 종류와 상관없이 **기울기를 구해서 반대로 조금 움직인다**는 규칙 하나로 모든 파라미터를 학습합니다.
:::

:::page{type="concept" id="ch03-code" layout="basic"}
# 코드로 따라가는 경사하강법

## 손실이 가장 작은 w 찾기

손실함수가 **L(w) = (w - 3)²** 이라고 합시다. 가장 낮은 점은 w = 3입니다. 이 함수의 기울기는 **2 × (w - 3)** 입니다. w = 0에서 출발해 다섯 걸음을 가 봅시다.

```python
w = 0.0    # 처음 위치
lr = 0.1   # 학습률

for step in range(1, 6):
    grad = 2 * (w - 3)   # 지금 위치의 기울기
    w = w - lr * grad    # 기울기 반대쪽으로 이동
    print(step, "번째 w:", round(w, 3))
```

```output
1 번째 w: 0.6
2 번째 w: 1.08
3 번째 w: 1.464
4 번째 w: 1.771
5 번째 w: 2.017
```

w가 3에 점점 가까워지고, 가까워질수록 한 걸음의 크기가 작아집니다. 기울기가 작아지기 때문입니다.

# 학습률 정하기

## 학습률을 바꿔 보기

같은 문제에서 학습률만 바꾸고 열 걸음씩 가 봅시다. 목표는 w = 3입니다.

```python
for lr in [0.01, 0.1, 1.1]:
    w = 0.0
    for step in range(10):
        w = w - lr * 2 * (w - 3)
    print("학습률", lr, "->", "w =", round(w, 2))
```

```output
학습률 0.01 -> w = 0.55
학습률 0.1 -> w = 2.68
학습률 1.1 -> w = -15.58
```

# 선형 회귀 모델

## 직선의 식

선형 회귀는 입력 x와 예측값 사이의 관계를 직선으로 나타냅니다.

**예측값 = w × x + b**

- **w**(가중치, weight): 직선의 기울기. x가 1 늘 때 예측값이 얼마나 느는지
- **b**(편향, bias): 직선의 절편. x가 0일 때의 예측값
- 학습이란 데이터에 가장 잘 맞는 **w**와 **b**를 찾는 것입니다.

::image{src="assets/ch04/candidate-lines.png" alt="같은 산점도 위에 기울기와 절편이 다른 직선 세 개를 그린 그래프. 하나는 점들을 잘 따라가고 나머지 둘은 크게 벗어난다" ratio="16:9" caption="그림 4-1 w와 b에 따라 달라지는 직선"}
:::

:::page{type="step-process" id="ch04-steps"}
# 학습 순서로 보는 선형 회귀

1장에서 배운 다섯 단계에 선형 회귀를 그대로 맞춰 봅시다.

## 파라미터 초깃값 정하기

w = 0, b = 0에서 시작합니다.

## 예측하기

모든 데이터에 대해 **예측값 = w × x + b** 를 계산합니다.

## 손실 계산하기

**오차 = 예측값 - 실제값** 을 구하고, 손실함수로 **MSE**를 사용합니다.

## 기울기 구하기

- w의 기울기 = 2 × 평균(오차 × x)
- b의 기울기 = 2 × 평균(오차)

## 파라미터 수정하기

- w = w - 학습률 × w의 기울기
- b = b - 학습률 × b의 기울기
:::

:::page{type="concept" id="ch04-gradient" layout="basic"}
# 기울기 식 이해하기

## 식이 뜻하는 것

MSE를 w와 b로 각각 미분하면 앞 페이지의 기울기 식이 나옵니다. 계산 과정보다 식이 뜻하는 바를 먼저 이해해 봅시다.

- **평균(오차)**: 예측이 전체적으로 높으면 양수가 되어 b를 줄입니다. 낮으면 음수가 되어 b를 늘립니다.
- **평균(오차 × x)**: x가 큰 데이터의 오차일수록 w에 더 큰 영향을 줍니다.
- 모든 오차가 0이면 두 기울기도 0이 되어 파라미터가 더 이상 바뀌지 않습니다.

> [!KEY_POINT]
> 기울기는 **오차**에 비례합니다. 많이 틀린 만큼 많이 고치고, 다 맞히면 멈춥니다. 이것이 오차 기반 학습이라는 이름의 뜻입니다.
:::

:::page{type="concept" id="ch04-code" layout="basic"}
# 선형 회귀 학습 코드

## 다섯 단계를 코드로 옮기기

NumPy를 사용하면 데이터 전체를 한 번에 계산할 수 있습니다. 주석의 번호는 학습 순서의 단계입니다.

```python
import numpy as np

x = np.array([1, 2, 3, 4, 5])       # 공부 시간
y = np.array([52, 58, 65, 70, 76])  # 시험 점수

w, b = 0.0, 0.0   # 처음 파라미터
lr = 0.05         # 학습률

for epoch in range(1, 1001):
    pred = w * x + b                  # 1. 예측
    error = pred - y                  # 2. 오차
    loss = np.mean(error ** 2)        # 3. 손실(MSE)
    grad_w = 2 * np.mean(error * x)   # 4. 기울기
    grad_b = 2 * np.mean(error)
    w = w - lr * grad_w               # 5. 수정
    b = b - lr * grad_b
    if epoch in [1, 10, 100, 1000]:
        print(epoch, round(loss, 2))
```

```output
1 4193.8
10 229.29
100 10.81
1000 0.16
```

첫 에포크의 손실은 4193.8이었지만 1000번째에는 0.16까지 줄었습니다.

# 로지스틱 회귀
## 확률로 예/아니오 판단하기

### 학습 목표

- 분류 문제에 선형 회귀를 그대로 쓰기 어려운 이유를 설명할 수 있다.
- 시그모이드 함수로 예측값을 확률로 바꿀 수 있다.
- 교차 엔트로피 손실과 경사하강법으로 로지스틱 회귀를 학습할 수 있다.

### 합격일까, 불합격일까?

이번에는 공부 시간으로 점수가 아니라 **합격(1)** 인지 **불합격(0)** 인지를 예측하려고 합니다. 정답이 0 또는 1뿐인 분류 문제입니다.

모델이 "합격"이라고 딱 잘라 말하기보다 "**합격할 확률 80%**"처럼 확률로 답하면 더 쓸모가 있습니다. 확률로 답하는 분류 모델이 **로지스틱 회귀**입니다.

:::page{type="concept" id="ch05-why-not-linear" layout="basic"}
# 직선으로 분류하면?

## 0과 1 밖으로 나가는 예측

합격 여부 데이터에 선형 회귀 직선을 그대로 맞추면 문제가 생깁니다.

::image{src="assets/ch05/linear-on-binary.png" alt="가로축 공부 시간, 세로축 합격 여부(0 또는 1)인 산점도 위에 직선을 그린 그래프. 직선이 왼쪽에서는 0 아래로, 오른쪽에서는 1 위로 뻗어 나간다" ratio="16:9" caption="그림 5-1 0과 1 데이터에 맞춘 직선"}

- 공부 시간이 길면 예측값이 1보다 커집니다. 확률 120%는 뜻이 없습니다.
- 공부 시간이 짧으면 예측값이 0보다 작아집니다.
- 그래서 직선의 출력을 **0과 1 사이**로 눌러 주는 함수가 필요합니다.
:::

:::page{type="concept" id="ch05-sigmoid" layout="basic"}
# 시그모이드 함수

## 어떤 숫자든 0과 1 사이로

**시그모이드**(sigmoid) 함수는 어떤 숫자 z가 들어와도 0과 1 사이의 값을 돌려줍니다. 그래프는 S자 모양입니다.

**시그모이드(z) = 1 ÷ (1 + e의 -z 제곱)**

::image{src="assets/ch05/sigmoid-curve.png" alt="가로축 z(-6~6), 세로축 0~1인 S자 시그모이드 곡선. z = 0에서 0.5를 지나고 0.5 높이에 가로 점선이 있다" ratio="16:9" caption="그림 5-2 시그모이드 함수"}

```python
import math

def sigmoid(z):
    return 1 / (1 + math.exp(-z))

for z in [-5, -1, 0, 1, 5]:
    print(z, "->", round(sigmoid(z), 3))
```

```output
-5 -> 0.007
-1 -> 0.269
0 -> 0.5
1 -> 0.731
5 -> 0.993
```

:::page{type="concept" id="ch05-model" layout="basic"}
# 로지스틱 회귀 모델

## 직선 위에 시그모이드 씌우기

로지스틱 회귀는 선형 회귀의 직선을 그대로 계산한 뒤, 그 결과를 시그모이드에 넣습니다.

**z = w × x + b**

**예측 확률 = 시그모이드(z)**

- **w**와 **b**는 선형 회귀와 똑같이 학습할 파라미터입니다.
- 예측 확률이 0.5 이상이면 합격(1), 0.5보다 작으면 불합격(0)으로 판단합니다.
- 예측 확률이 정확히 0.5가 되는 x가 합격과 불합격을 가르는 **결정 경계**입니다.

> [!KEY_POINT]
> 로지스틱 회귀는 **직선 + 시그모이드**입니다. 직선이 점수를 매기고, 시그모이드가 그 점수를 확률로 바꿉니다.
:::

:::page{type="concept" id="ch05-mse-problem" layout="basic"}
# MSE를 쓰지 않는 이유

## 울퉁불퉁해지는 손실

로지스틱 회귀에 MSE를 그대로 쓰면, 시그모이드 때문에 손실 곡선이 매끄러운 U자가 되지 않습니다. 평평한 구간이 길게 생겨 기울기가 거의 0이 되는 곳이 많아지고, 경사하강법이 잘 내려가지 못합니다.

::image{src="assets/ch05/mse-vs-bce-shape.png" alt="두 그래프를 나란히 비교한 그림. 왼쪽은 로지스틱 회귀에 MSE를 쓴 손실 곡선으로 양옆이 평평하게 누운 모양, 오른쪽은 교차 엔트로피 손실로 매끄러운 U자 모양" ratio="2:1" width="full" caption="그림 5-3 로지스틱 회귀에서 MSE와 교차 엔트로피의 손실 모양"}

그래서 로지스틱 회귀에는 확률 예측에 맞게 만든 **교차 엔트로피** 손실을 씁니다.
:::

:::page{type="concept" id="ch05-bce" layout="basic"}
# 교차 엔트로피 손실

## 자신 있게 틀리면 크게 벌 받는다

**이진 교차 엔트로피**(binary cross-entropy)는 정답 y가 0 또는 1이고 예측 확률이 p일 때 다음과 같이 계산합니다.

**손실 = -(y × log p + (1 - y) × log(1 - p))**

- 정답이 1이면 **-log p** 만 남습니다. p가 1에 가까울수록 손실이 0에 가깝습니다.
- 정답이 0이면 **-log(1 - p)** 만 남습니다. p가 0에 가까울수록 손실이 작습니다.

```python
import math

def bce(y, p):   # y: 정답, p: 예측 확률
    return -(y * math.log(p)
             + (1 - y) * math.log(1 - p))

for p in [0.9, 0.5, 0.1]:
    print("정답 1, 예측", p, "->", round(bce(1, p), 3))
```

```output
정답 1, 예측 0.9 -> 0.105
정답 1, 예측 0.5 -> 0.693
정답 1, 예측 0.1 -> 2.303
```
:::

# 학습 순서로 보는 로지스틱 회귀

선형 회귀와 같은 다섯 단계입니다. 달라진 부분만 눈여겨보세요.

## 파라미터 초깃값 정하기

w = 0, b = 0에서 시작합니다.

## 예측하기

**예측 확률 = 시그모이드(w × x + b)** 를 계산합니다. 선형 회귀에 시그모이드가 더해졌습니다.

## 손실 계산하기

손실함수로 MSE 대신 **교차 엔트로피**를 사용합니다.

## 기울기 구하기

- w의 기울기 = 평균((예측 확률 - 정답) × x)
- b의 기울기 = 평균(예측 확률 - 정답)

## 파라미터 수정하기

선형 회귀와 똑같이 기울기의 반대 방향으로 학습률만큼 옮깁니다.
:::

# 로지스틱 회귀 학습 코드

## 합격 여부 학습하기

공부 시간 8개와 합격 여부(1은 합격, 0은 불합격) 데이터로 학습합니다. 선형 회귀 코드와 거의 같은 모양입니다.

```python
import numpy as np

x = np.array([1, 2, 3, 4, 5, 6, 7, 8])  # 공부 시간
y = np.array([0, 0, 0, 1, 0, 1, 1, 1])  # 합격 여부

w, b = 0.0, 0.0
lr = 0.1

for epoch in range(1, 3001):
    p = 1 / (1 + np.exp(-(w * x + b)))    # 확률 예측
    loss = -np.mean(y * np.log(p)
                    + (1 - y) * np.log(1 - p))
    grad_w = np.mean((p - y) * x)
    grad_b = np.mean(p - y)
    w = w - lr * grad_w
    b = b - lr * grad_b
    if epoch in [1, 100, 1000, 3000]:
        print(epoch, round(loss, 3))
print("w =", round(w, 2), " b =", round(b, 2))
```

```output
1 0.693
100 0.479
1000 0.322
3000 0.313
w = 1.23  b = -5.51
```

# 학습 결과 확인하기

## 합격 확률 예측하기

학습된 w와 b로 새로운 공부 시간의 합격 확률을 계산해 봅시다.

```python
import math

w, b = 1.23, -5.51   # 학습이 끝난 파라미터

for hours in [2, 4.5, 7]:
    p = 1 / (1 + math.exp(-(w * hours + b)))
    result = "합격" if p >= 0.5 else "불합격"
    print(hours, "시간:", round(p, 2), result)
```

```output
2 시간: 0.05 불합격
4.5 시간: 0.51 합격
7 시간: 0.96 합격
```

# 두 모델 한눈에 비교하기

두 모델은 같은 학습 순서를 따르고, 모델과 손실함수만 다릅니다.

| 단계 | 선형 회귀 | 로지스틱 회귀 |
|---|---|---|
| 문제 | 회귀(숫자 예측) | 분류(0 또는 1) |
| 예측 | w × x + b | 시그모이드(w × x + b) |
| 손실함수 | MSE | 교차 엔트로피 |
| w의 기울기 | 2 × 평균(오차 × x) | 평균(오차 × x) |
| 파라미터 수정 | 경사하강법 | 경사하강법 |

> [!KEY_POINT]
> 로지스틱 회귀에서 오차는 **예측 확률 - 정답**입니다. 모델과 손실은 달라도, 기울기는 두 모델 모두 **오차 × 입력** 모양이 됩니다.
:::
