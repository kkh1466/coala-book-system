# 데이터와 그래프
## AI와 함께 데이터를 그래프로 표현하기

### 학습 목표

- 표 데이터의 행과 열이 무엇을 의미하는지 설명할 수 있다.
- 막대그래프, 꺾은선그래프, 산점도, 히스토그램의 기본 용도를 구분할 수 있다.
- 알고플로에서 학생 신체정보 데이터를 불러오고 확인할 수 있다.
- AI에게 그래프 제작을 요청하고 결과를 확인할 수 있다.
- 혈액형과 성별을 함께 사용하여 인원을 비교할 수 있다.

### 데이터를 표로 정리하면

학생 한 명의 키와 몸무게는 그냥 적어 두어도 됩니다. 하지만 학생이 여러 명이면 어떨까요? 정보를 **표**로 정리하면 여러 대상의 정보를 한눈에 보고 서로 비교하기 쉬워집니다.

이번 단원에서는 표로 정리된 데이터를 AI와 함께 그래프로 그려 봅니다.
:::

:::page{type="concept" id="ch03-row-column" layout="basic"}
# 행과 열

## 표를 읽는 두 방향

표는 가로 방향과 세로 방향으로 읽을 수 있습니다. 아래 표에서 박서준의 줄과 키의 칸을 살펴봅시다.

::image{src="assets/행과 열로 보는 학생 표.png" alt="이름, 키, 몸무게, 혈액형, 좋아하는 운동 열이 있는 학생 네 명의 표. 박서준의 가로 줄에 행(row), 키의 세로 줄에 열(column)이 표시되어 있다" ratio="2.19" width="full" caption="행과 열로 보는 학생 표"}

- **행(row):** 가로 방향입니다. 박서준의 행에는 박서준 한 학생의 정보가 모두 들어 있습니다.
- **열(column):** 세로 방향입니다. 키의 열에는 모든 학생의 키라는 하나의 항목이 모여 있습니다.
- **특성(feature):** 데이터 분석에서 분석에 사용하는 항목을 특성이라고도 부릅니다. 분석 목적에 따라 어떤 열을 특성으로 쓸지 정합니다.

> [!TIP]
> 위 표는 행과 열을 설명하기 위한 예시입니다. 실습에서 불러올 데이터에는 이름과 좋아하는 운동 항목이 없습니다.
:::

:::page{type="concept" id="ch03-four-graphs" layout="basic"}
# 기본 그래프 네 가지

## 무엇을 보고 싶은지에 따라 고릅니다

::image{src="assets/graphs_2x2.png" alt="막대그래프, 꺾은선그래프, 산점도, 히스토그램 네 가지 예시가 2행 2열로 배치되어 있고 각 그래프 아래에 한 줄 설명이 있다" ratio="1.12" width="full"}

- **막대그래프:** 혈액형처럼 **종류별** 개수나 크기를 비교합니다.
- **꺾은선그래프:** 요일별 기온처럼 순서에 따른 변화를 봅니다.
- **산점도:** 공부 시간과 점수처럼 두 수치 항목의 관계를 봅니다.
- **히스토그램:** 시험 점수처럼 **수치 구간별** 분포를 봅니다.
:::

:::page{type="concept" id="ch03-load-step1" layout="basic"}
# 알고플로에서 데이터 불러오기

## 데이터 버튼 누르기

그래프를 그리려면 먼저 데이터가 있어야 합니다. 알고플로에는 학생 신체 정보 데이터가 준비되어 있어 버튼 하나로 불러올 수 있습니다.

::image{src="assets/데이터 버튼 클릭 안내.png" alt="코드 셀의 오른쪽 위 메뉴에서 데이터 버튼이 강조되어 있고 클릭이라는 안내가 붙어 있다" ratio="3.69" width="full" caption="코드 셀 오른쪽 위의 데이터 버튼"}

- 코드 셀 오른쪽 위의 **데이터** 버튼을 누릅니다.
- 데이터셋을 고르는 창이 열립니다.
:::

:::page{type="concept" id="ch03-load-step2" layout="basic"}
# 데이터셋 고르기

## 학생 신체 정보 데이터 불러오기

::image{src="assets/교육·학생 데이터 선택 안내.png" alt="데이터셋 불러오기 창. 왼쪽 목록의 교육·학생이 1번 클릭, 오른쪽의 학생 신체 정보 데이터(결측x) 카드가 2번 클릭으로 표시되어 있고 아래에 불러오기 버튼이 있다" ratio="1.17" width="text" caption="데이터셋 불러오기 창"}

1. 왼쪽 목록에서 **교육·학생**을 누릅니다.
2. **학생 신체 정보 데이터(결측x)**를 선택합니다.
3. 아래의 **불러오기** 버튼을 누릅니다.

이름의 **결측x**는 비어 있는 값이 없는 데이터라는 뜻입니다.
:::

:::page{type="concept" id="ch03-load-step3" layout="basic"}
# 실행하고 데이터 확인하기

## 불러온 데이터 살펴보기

불러오기를 누르면 데이터를 불러오는 코드가 셀에 들어옵니다. 셀 왼쪽의 **실행 버튼**을 누르고 아래에 나타나는 표를 확인합니다.

::image{src="assets/실행 버튼과 데이터셋 확인 가이드.png" alt="데이터를 불러오는 코드가 들어간 셀과 왼쪽의 실행 버튼, 셀 아래에 성별, 키, 몸무게, 혈액형 열과 0부터 4까지 다섯 행이 표시된 표" ratio="2.15" width="full" caption="실행 버튼을 누르고 데이터셋 확인하기"}

- 표에는 데이터의 **앞부분 5행**만 보입니다. 전체 데이터는 학생 200명의 정보입니다.
- 표 맨 왼쪽의 0부터 4는 행 번호입니다. 데이터 항목이 아닙니다.
- 불러온 표 데이터는 코드에서 **df**라는 이름으로 사용합니다.
:::

:::page{type="comparison" id="ch03-dataset-columns"}
# 학생 신체 정보 데이터의 열

불러온 데이터는 200행과 4개의 열로 되어 있습니다. 한 행이 학생 한 명이고, 열은 다음 네 가지입니다.

| 열 이름 | 내용 |
|---|---|
| 성별 | 남자 또는 여자 |
| 키 | 학생의 키를 나타내는 수치 |
| 몸무게 | 학생의 몸무게를 나타내는 수치 |
| 혈액형 | A, B, O, AB |

> [!KEY_POINT]
> 화면에 5행만 보여도 그래프는 200행 전체를 사용합니다. 성별과 혈액형은 종류를 나타내고, 키와 몸무게는 수치를 나타냅니다.
:::

:::page{type="practice-opening" id="ch03-practice-1" practice="003-1" practice-kind="그래프 실습" platform="실습하기"}
# 키의 분포와 키·몸무게의 관계 알아보기

네 가지 그래프 중 **히스토그램**과 **산점도**를 사용합니다. 불러온 데이터를 바탕으로 알고플로의 AI 기능에 그래프 코드를 요청하고, 코드 셀에 넣어 실행해 봅시다.

예시 프롬프트: "이미 불러온 df에는 성별, 키, 몸무게, 혈액형 열이 있어. 키의 히스토그램과 가로축이 키, 세로축이 몸무게인 산점도를 각각 그리는 코드를 만들어 줘. 알고플로의 노트북 셀에서 실행하고, 제목과 축 이름도 표시해 줘."

> [!TIP]
> 데이터는 이미 불러왔으므로 다시 불러오거나 새로 만들어 달라고 요청하지 않습니다. 데이터 불러오기 셀을 먼저 실행해 두세요.

- [ ] 키의 히스토그램을 그려 자료가 많이 모인 구간을 확인할 수 있다.
- [ ] 키와 몸무게의 산점도를 그려 두 항목의 관계를 살펴볼 수 있다.
- [ ] 원하는 그래프와 사용할 항목을 AI에게 구체적으로 요청할 수 있다.
:::

:::page{type="concept" id="ch03-practice-1-check" layout="basic"}
# 실습 003-1 진행과 결과 확인

## 진행 흐름

1. 데이터 불러오기 셀을 먼저 실행합니다.
2. 알고플로의 AI 기능에 예시 프롬프트처럼 그래프 제작을 요청합니다.
3. 생성된 코드를 코드 셀에 넣고 실행합니다.
4. 히스토그램과 산점도가 나타나는지 확인합니다.

## 그래프를 보고 답해 봅시다

- 키의 히스토그램에서 학생이 가장 많이 모인 구간은 어디인가요?
- 산점도에서 점 하나는 무엇을 나타내나요?
- 키가 커질수록 몸무게도 대체로 커지는 모습이 보이나요?

> [!KEY_POINT]
> 히스토그램은 키라는 **한 항목의 분포**를, 산점도는 키와 몸무게라는 **두 수치 항목의 관계**를 보여 줍니다.
:::

:::page{type="practice-opening" id="ch03-practice-2" practice="003-2" practice-kind="그래프 실습" platform="실습하기"}
# 혈액형별 남자·여자 인원 비교하기

이번에는 **혈액형**과 **성별**이라는 두 열을 함께 사용합니다. 혈액형별로 남자와 여자 인원을 세어, 각 혈액형 안에서 두 막대를 나란히 놓은 막대그래프를 만들어 봅시다.

예시 프롬프트: "불러온 df에서 혈액형별 남자와 여자 인원을 세어 막대그래프로 그려 줘. 가로축은 A, B, O, AB 순서, 세로축은 학생 수로 하고, 각 혈액형의 남자와 여자 막대를 다른 색으로 나란히 표시해 줘. 제목과 범례를 넣고 세로축은 0부터 시작해 줘."

> [!TIP]
> 막대를 겹치거나 쌓지 않고 나란히 놓아야 남자와 여자 인원을 바로 비교할 수 있습니다.

- [ ] 혈액형과 성별을 함께 사용하여 학생 수를 비교할 수 있다.
- [ ] 막대 색과 범례로 남자와 여자를 구분할 수 있다.
- [ ] 그래프를 보고 혈액형별 남녀 인원 차이를 설명할 수 있다.
:::

:::page{type="concept" id="ch03-practice-2-graph" layout="basic"}
# 그래프는 이렇게 구성합니다

## 두 열로 인원 세기

먼저 학생을 혈액형별로 나눕니다. 그런 다음 각 혈액형 안에서 다시 남자와 여자로 나누어 인원을 셉니다. 이렇게 세어진 인원수가 막대의 높이가 됩니다.

## 그래프 구성

- 가로축: 혈액형 A, B, O, AB
- 세로축: 학생 수
- 각 혈액형마다 남자와 여자 막대를 나란히 표시
- 남자와 여자를 서로 다른 색으로 표시
- 범례에 남자와 여자 표시
- 세로축은 0부터 시작

> [!KEY_POINT]
> AI가 만든 코드의 모양은 달라도 괜찮습니다. 요청한 대로 그래프가 올바르게 나타나는지 확인하는 것이 중요합니다.
:::

:::page{type="concept" id="ch03-practice-2-check" layout="basic"}
# 실습 003-2 진행과 결과 확인

## 진행 흐름

1. 알고플로의 AI 기능에 예시 프롬프트처럼 그래프 제작을 요청합니다.
2. 생성된 코드를 코드 셀에 넣고 실행합니다.
3. 혈액형마다 남녀 막대가 나란히 나타나는지 확인합니다.
4. 범례를 보고 두 막대의 높이를 비교합니다.

## 그래프를 보고 답해 봅시다

- 각 혈액형에서 남자와 여자 중 누가 더 많은가요?
- 남녀 인원 차이가 가장 큰 혈액형은 무엇인가요?
- 남녀 인원을 합했을 때 학생이 가장 많은 혈액형은 무엇인가요?

> [!TIP]
> 답은 실제 그래프를 보고 찾습니다. 막대의 높이를 비교하고, 범례로 어느 막대가 남자이고 여자인지 확인하세요.
:::
