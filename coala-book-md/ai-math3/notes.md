# 3단원 교재 제작 요청

이번에 제공한 이미지 5개, 학생 신체정보 데이터, 아래 구성과 실습 지시만을 사용하여 고등학생용 3단원 교재를 작성해 주세요. 완성된 이전 단원의 내용을 가져오거나 다시 설명하지 마세요. AI 기능은 그래프를 그리는 실습 도구로만 활용합니다.

단원명은 **「3. 데이터와 그래프」**, 부제는 **「AI와 함께 데이터를 그래프로 표현하기」**로 해 주세요.

내용은 표 데이터 설명, 그래프 개념 설명, 알고플로의 데이터 불러오기 안내, 그래프 실습 두 개로 한정하세요. 학생 눈높이에 맞는 짧은 설명과 실습 목표를 사용하고, 평가 기준·제출 과제·수업 시간표·추가 프로젝트는 넣지 마세요.

## 필수 구성 순서

1. 표 데이터와 행·열 설명
2. 기본 그래프 네 가지의 개념 설명 — 첨부 이미지 활용, 정확히 한 페이지 분량
3. 알고플로에서 데이터 불러오기 — 첨부 이미지 세 개 활용
4. 실습 1: 키의 히스토그램과 키·몸무게 산점도 그리기
5. 실습 2: 혈액형별 남자·여자 인원을 막대그래프로 비교하기

이 순서를 유지하고, 데이터 불러오기 안내는 별도의 세 번째 실습으로 번호를 붙이지 마세요. 그래프 실습은 두 개만 구성해 주세요.

## 학습 목표

- 표 데이터의 행과 열이 무엇을 의미하는지 설명할 수 있다.
- 막대그래프, 꺾은선그래프, 산점도, 히스토그램의 기본 용도를 구분할 수 있다.
- 알고플로에서 학생 신체정보 데이터를 불러오고 확인할 수 있다.
- AI에게 그래프 제작을 요청하고 결과를 확인할 수 있다.
- 혈액형과 성별을 함께 사용하여 인원을 비교할 수 있다.

## 1. 표 데이터 설명

### 사용할 이미지

**「행과 열로 보는 학생 표.png」**

이미지를 활용하여 데이터를 표로 정리하면 여러 대상의 정보를 비교하기 쉽다는 점을 설명하세요.

- 행(row): 가로 방향이며, 이 예시에서는 한 학생의 정보를 나타냅니다.
- 열(column): 세로 방향이며, 이름·키·몸무게·혈액형·좋아하는 운동처럼 하나의 항목을 나타냅니다.
- 데이터 분석에서 분석에 사용하는 항목을 특성(feature)이라고 부르기도 한다는 점을 짧게 소개하세요. 모든 열이 반드시 분석에 사용할 특성이라고 단정하지 마세요.

이미지에서 표시한 박서준의 행과 키의 열을 예로 들어 설명하면 됩니다. 학생이 코드를 읽거나 작성해야 하는 활동은 넣지 마세요.

**자료 구분:** 이 이미지는 행과 열을 설명하기 위한 예시 표입니다. 실제 실습 데이터와 동일한 표라고 설명하지 마세요. 실제 실습 데이터에는 이름이나 좋아하는 운동 항목이 없습니다.

## 2. 기본 그래프 개념 설명 — 한 페이지

### 사용할 이미지

**「graphs_2x2(1).png」**

이 이미지를 그대로 활용하여 네 그래프의 기본 개념을 한 페이지에 설명하세요. 네 종류를 여러 페이지로 나누거나 새로운 그래프 이미지를 추가로 만들지 마세요. 이미지에 이미 설명이 포함되어 있으므로 중복되는 긴 설명을 덧붙이지 말고, 읽을 수 있는 크기로 배치하세요.

설명 범위는 다음과 같습니다.

- 막대그래프: 혈액형처럼 종류별 개수나 크기를 비교합니다. 범주를 나타내는 막대 사이에는 간격이 있습니다.
- 꺾은선그래프: 요일별 기온처럼 시간이나 의미 있는 순서에 따른 변화를 점과 선으로 보여 줍니다.
- 산점도: 공부 시간과 점수처럼 두 수치 항목 사이의 관계를 점의 위치로 보여 줍니다.
- 히스토그램: 시험 점수처럼 수치 자료를 구간으로 나누어 각 구간에 자료가 몇 개 있는지 보여 줍니다. 연속된 구간의 막대는 붙여 표현합니다.

막대그래프와 히스토그램은 각각 **종류별 비교**와 **수치 구간별 분포**라는 차이를 짧게 강조하세요.

이미지 속 혈액형 인원, 기온, 공부 시간, 시험 점수는 그래프 개념을 설명하는 예시입니다. 실제 학생 신체정보 데이터의 값이라고 설명하지 마세요. 실제 데이터에는 시간에 따른 변화 항목이 없으므로 꺾은선그래프는 개념만 소개하고 실습에서는 사용하지 않습니다.

## 3. 알고플로에서 학생 신체정보 데이터 불러오기

이미지 세 개를 아래 순서대로 사용하여 실제 화면을 따라 할 수 있도록 안내하세요. 이미지 속 버튼 이름과 표시를 그대로 참고하고, 화면에 없는 기능이나 절차를 추가하지 마세요.

### 단계 1. 데이터 버튼 클릭

사용 이미지: **「데이터 버튼 클릭 안내.png」**

코드 셀 우측 상단의 **‘데이터’** 버튼을 클릭하도록 안내하세요.

### 단계 2. 데이터셋 선택 및 불러오기

사용 이미지: **「교육·학생 데이터 선택 안내.png」**

데이터셋 불러오기 창에서 다음 순서로 진행합니다.

1. 왼쪽의 **‘교육·학생’**을 클릭합니다.
2. **‘학생 신체 정보 데이터(결측x)’**를 선택합니다.
3. 하단의 **‘불러오기’** 버튼을 클릭합니다.

‘결측x’는 비어 있는 값이 없는 데이터라는 뜻이라고 한 문장으로 설명하세요. 결측값 처리 방법까지 확장하지 마세요.

### 단계 3. 실행하고 데이터 확인

사용 이미지: **「실행 버튼과 데이터셋 확인 가이드.png」**

데이터 불러오기 코드가 들어간 셀의 왼쪽 실행 버튼을 누르고, 아래에 나타나는 표를 확인하도록 안내하세요.

실제 데이터는 **학생 200명의 정보, 200행과 4개 열**로 구성됩니다.

| 열 이름 | 내용 |
|---|---|
| 성별 | 남자 또는 여자 |
| 키 | 학생의 키를 나타내는 수치 |
| 몸무게 | 학생의 몸무게를 나타내는 수치 |
| 혈액형 | A, B, O, AB |

화면에는 데이터의 앞부분 5행만 표시됩니다. 전체 데이터가 5명뿐이라고 오해하지 않도록 짧게 설명하세요. 표 맨 왼쪽의 0~4는 행 번호이며, 별도의 데이터 항목으로 세지 마세요.

교재 제작 참고용 데이터 주소:
https://s3.ap-northeast-2.amazonaws.com/page.thecoala.io/DataScience/dataset/student_data.csv

학생은 알고플로의 데이터 버튼으로 불러옵니다. 별도의 다운로드, 파일 업로드, URL 입력 과정을 추가하지 마세요. 이미지에서는 데이터가 `df`라는 이름으로 준비됩니다. 학생에게는 ‘불러온 표 데이터를 코드에서 df라는 이름으로 사용한다’ 정도로만 설명하세요. pandas나 데이터 불러오기 코드의 문법을 자세히 가르치지 마세요.

## 4. 실습 1 — 키의 분포와 키·몸무게의 관계 알아보기

실습 번호는 **003-1**로 해 주세요.

### 실습 소개

이 단원에서 소개한 네 그래프 중 **히스토그램과 산점도**를 사용합니다. 불러온 데이터를 바탕으로 알고플로의 AI 기능에 그래프 코드를 요청하고 실행하도록 구성하세요.

### 실습 목표

- 키의 히스토그램을 그려 자료가 많이 모인 구간을 확인할 수 있다.
- 키와 몸무게의 산점도를 그려 두 항목의 관계를 살펴볼 수 있다.
- 원하는 그래프와 사용할 항목을 AI에게 구체적으로 요청할 수 있다.

### 예시 프롬프트

> 이미 불러온 df에는 성별, 키, 몸무게, 혈액형 열이 있어. 키의 히스토그램과 가로축이 키, 세로축이 몸무게인 산점도를 각각 그리는 코드를 만들어 줘. 알고플로의 노트북 셀에서 실행하고, 제목과 축 이름도 표시해 줘.

데이터는 이미 불러왔으므로 다시 불러오거나 임의의 데이터를 생성하도록 요청하지 마세요. 그래프에는 앞부분 5행만이 아니라 전체 200행을 사용합니다.

### 진행 흐름

1. 데이터 불러오기 셀을 먼저 실행합니다.
2. 알고플로의 AI 기능에 그래프 제작을 요청합니다.
3. 생성된 코드를 코드 셀에 넣고 실행합니다.
4. 히스토그램과 산점도를 확인합니다.

AI나 바이브 코딩의 개념, 사람과 AI의 역할, 일반적인 프롬프트 작성법, 주피터 노트북 소개는 별도 설명으로 추가하지 마세요. 실습에는 그래프 제작에 필요한 요청문과 실행 안내만 넣으세요.

### 결과 확인 질문

- 키의 히스토그램에서 학생이 가장 많이 모인 구간은 어디인가요?
- 산점도에서 점 하나는 무엇을 나타내나요?
- 키가 커질수록 몸무게도 대체로 커지는 모습이 보이나요?

히스토그램은 키라는 한 항목의 분포, 산점도는 키와 몸무게라는 두 수치 항목의 관계를 보여 준다는 점을 정리하세요. 실제 그래프를 확인하지 않고 특정 구간이나 관계를 정답으로 단정하지 마세요.

## 5. 실습 2 — 혈액형별 남자·여자 인원 비교하기

실습 번호는 **003-2**로 해 주세요.

### 실습 소개

이번에는 **혈액형과 성별이라는 두 열을 함께 사용**합니다. 혈액형별로 남자와 여자 인원을 세어, 각 혈액형 안에서 두 막대를 나란히 표시하는 막대그래프를 만듭니다.

겹치거나 쌓은 막대그래프가 아니라 **나란히 놓인 막대그래프**로 구성하세요. ‘분포’는 이번 실습에서 비율이 아닌 인원수 비교를 의미합니다.

### 실습 목표

- 혈액형과 성별을 함께 사용하여 학생 수를 비교할 수 있다.
- 막대 색과 범례로 남자와 여자를 구분할 수 있다.
- 그래프를 보고 혈액형별 남녀 인원 차이를 설명할 수 있다.

### 그래프 구성

- 가로축: 혈액형 A, B, O, AB
- 세로축: 학생 수
- 각 혈액형마다 남자와 여자 막대를 나란히 표시
- 남자와 여자를 서로 다른 색으로 표시
- 범례에 남자와 여자 표시
- 세로축은 0부터 시작

‘혈액형별로 나눈 뒤, 다시 성별로 나누어 인원을 센다’는 처리 과정을 쉬운 말로 설명하세요. 그룹화 함수나 코드 문법 설명으로 확장하지 마세요.

### 예시 프롬프트

> 불러온 df에서 혈액형별 남자와 여자 인원을 세어 막대그래프로 그려 줘. 가로축은 A, B, O, AB 순서, 세로축은 학생 수로 하고, 각 혈액형의 남자와 여자 막대를 다른 색으로 나란히 표시해 줘. 제목과 범례를 넣고 세로축은 0부터 시작해 줘.

### 진행 흐름

1. 알고플로의 AI 기능에 그래프 제작을 요청합니다.
2. 생성된 코드를 실행합니다.
3. 혈액형마다 남녀 막대가 나란히 나타나는지 확인합니다.
4. 범례를 보고 두 막대의 높이를 비교합니다.

### 결과 확인 질문

- 각 혈액형에서 남자와 여자 중 누가 더 많은가요?
- 남녀 인원 차이가 가장 큰 혈액형은 무엇인가요?
- 남녀 인원을 합했을 때 학생이 가장 많은 혈액형은 무엇인가요?

학생이 실제 그래프를 보고 답하도록 구성하고, 계산하지 않은 인원수나 비교 결과를 임의로 넣지 마세요.

- 표 설명용 예시, 그래프 개념용 예시, 실제 실습 데이터는 서로 구분하세요.
