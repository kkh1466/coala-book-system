# 선형회귀 만들기
## 데이터로 만들고 그래프로 설명하기

### 학습 목표

- 데이터를 고르고 어떤 숫자를 예측할지 정할 수 있다.
- 입력할 x 열과 예측할 y 열을 구분할 수 있다.
- 필요한 전처리를 하고 무엇을 바꾸었는지 설명할 수 있다.
- 0~15회 학습하는 과정을 그래프로 나타낼 수 있다.
- 만든 식과 각 파라미터의 실제 값을 확인할 수 있다.
- 사용한 열, 전처리, 파라미터와 그래프를 결과 분석 카드에 정리할 수 있다.

### 이번에는 직접 만들어 봅시다

주피터 노트북의 **데이터** 메뉴에는 여러 데이터셋이 준비되어 있습니다. 관심 있는 데이터를 불러와 살펴보고, 그 안의 정보로 다른 숫자를 예측하는 나만의 선형회귀식을 만들어 봅시다.

7~10단원에서 배운 내용을 활용해 필요한 전처리를 하고, 경사하강법으로 학습합니다. **0~15회 동안 예측이 어떻게 바뀌는지** 그래프로 확인합니다.

모델을 만든 뒤에는 **결과 분석 카드**를 작성합니다. 어떤 열을 골랐고 어떻게 처리했는지, 식의 파라미터는 얼마인지 자신의 실행 결과로 설명해 봅시다.
:::

:::page{type="practice-opening" id="practice-011-1" practice="011-1" practice-kind="모델 만들기" platform="주피터 노트북에서 실습하기"}
# 나만의 선형회귀식 만들기

관심 있는 데이터셋을 하나 골라 무엇을 예측할지 정해 봅시다. 예측할 y 열과 입력할 x 열을 고르고, 필요하면 숫자의 범위를 맞추거나 글자를 숫자로 바꿉니다.

AI-chat으로 학습 코드를 만들고 실행합니다. 학습 전인 0회부터 15회까지의 변화를 그래프로 나타내고, 15회 학습한 식과 파라미터 값을 확인하세요.

> [!TIP]
> 처음에는 x 하나로 시작해도 좋고, 여러 열을 사용해도 좋습니다. 데이터나 열을 고른 이유, 전처리한 내용을 메모해 두면 다음 활동에서 카드를 쓰기 쉽습니다.

- [ ] 데이터와 x·y를 직접 고를 수 있다.
- [ ] 필요한 전처리를 하고 바뀐 열로 학습할 수 있다.
- [ ] 0~15회 그래프와 15회 학습한 식의 파라미터를 확인할 수 있다.
:::

:::page{type="step-process" id="ch11-prepare-data"}
# 데이터와 예측할 내용 정하기

데이터를 고르고 다음 순서로 준비해 봅시다.

## 데이터 불러오고 살펴보기

코드 셀의 **데이터** 버튼을 누르고 관심 있는 데이터셋을 골라 **불러오기**를 누릅니다. 준비된 셀을 실행한 뒤 열 이름과 앞부분의 값을 확인하세요.

## 입력할 x와 예측할 y 고르기

**y는 예측할 숫자 한 열**, **x는 예측에 쓸 열**입니다. x는 한 개 또는 여러 개를 고릅니다.

y를 x에 다시 넣지는 마세요. 정답을 입력으로 주는 일이 됩니다. 학생 번호처럼 숫자여도 예측에 도움이 되는 정보인지 생각해 보세요.

## 필요한 전처리 하기

필요하면 표준화·정규화나 인코딩을 합니다. 원본을 남겨 두고 바꾼 열로 학습하세요. 어느 열을 어떻게 바꿨는지 적어 둡니다.

AI-chat 요청 예시: 선택한 x 열의 숫자는 표준화하고, 글자는 원핫 인코딩해 줘. 원본은 남겨 두고 바뀐 열 이름을 알려 줘.
:::

# 학습하는 모습을 그래프로 보면

## 몸무게로 키를 예측하는 예시

::image{src="assets/학습과정이미지.png" alt="몸무게로 키를 예측하는 학습 과정 예시. 두 축 모두 표준화한 값이며 회색 점은 실제 데이터이다. 0회의 수평선에서 시작해 1회부터 15회까지 예측 직선이 점들이 모인 방향에 가까워진다" ratio="1.697095" width="full" caption="입력이 하나일 때 0~15회 학습하며 직선이 바뀌는 모습"}

- **가로축은 몸무게, 세로축은 키**입니다. 이 그림에서는 두 값 모두 표준화했습니다.
- **회색 점**은 실제 데이터이고, **여러 직선**은 각 횟수에서의 예측식입니다.
- **0회**는 학습 전 상태입니다. 이 예시는 수평선으로 시작합니다.
- **1~15회**로 학습하며 직선이 점들의 방향에 가까워집니다. 오른쪽 설명에서 각 선의 학습 횟수를 확인하세요.

표준화한 값이므로 축의 0은 0kg나 0cm가 아닙니다. 평균을 기준으로 읽습니다. 자신이 다른 열을 고르면 축 이름과 그래프 모양도 달라집니다.

이 그림은 참고 예시입니다. 다음에는 **자신이 고른 데이터**로 학습 과정을 그려 봅시다.
:::

:::page{type="concept" id="ch11-train-and-plot" layout="basic"}
# AI-chat으로 학습 과정 그리기

현재 식으로 예측하고, 손실을 구하고, 파라미터를 한 번 바꾸는 것을 **1회**로 셉니다. **0회는 바꾸기 전 상태**이므로 0~15회는 모두 **16개 시점**입니다.

대괄호 안은 학습에 쓸 실제 열 이름으로 바꾸세요.

## x가 하나일 때

x는 [x 열], y는 [y 열]로 정하고 MSE를 줄이도록 경사하강법으로 15회 학습해 줘. 0~15회의 예측 직선을 산점도에 겹쳐 그리고, 15회 학습한 식과 파라미터 값을 보여 줘.

## x가 여러 개일 때

여러 입력을 쓰는 식은 앞의 산점도 위 직선 하나로 나타내기 어렵습니다. 대신 **학습 횟수에 따른 손실값**을 선 그래프로 확인합니다.

x는 [x 열들], y는 [y 열]로 MSE를 줄이도록 경사하강법으로 15회 학습해 줘. 0~15회 손실을 선 그래프로 그리고, 15회 학습한 식과 각 파라미터 값을 보여 줘.

코드를 실행해 **0회와 15회**, 식과 파라미터 값을 확인하세요.

> [!KEY_POINT]
> 15회는 과정을 관찰할 횟수이며 학습의 완성을 뜻하지 않습니다. 손실이 커지면 전처리와 학습률을 확인하세요.
:::

# 결과 분석 카드 작성하기

선형회귀식과 그래프를 만든 다음, 실제로 한 일을 결과 분석 카드에 정리해 봅시다. 사용한 데이터와 열, 전처리한 내용, 파라미터 값을 기록합니다.

그래프를 보며 0회와 15회 사이에 무엇이 달라졌는지 설명합니다. 다른 사람이 읽어도 어떤 정보로 무엇을 예측했는지 알 수 있게 써 보세요.

> [!TIP]
> 그래프를 만든 코드 셀 아래의 ‘아래에 추가’에서 **결과 분석**을 누르면 카드가 열립니다. 제공된 그림의 내용을 옮기지 말고, 자신이 실행한 결과로 채우세요.

- [ ] 사용한 데이터와 모든 x 열, y 열을 정리할 수 있다.
- [ ] 전처리한 내용과 식의 실제 파라미터 값을 기록할 수 있다.
- [ ] 자신의 학습 과정 그래프를 붙이고 결과를 설명할 수 있다.
:::

:::page{type="comparison" id="ch11-record-data"}
# 데이터와 x·y, 전처리 기록하기

제목에는 무엇으로 무엇을 예측했는지 씁니다. 자신이 선택한 데이터와 열을 아래 항목에 맞게 정리하세요.

| 카드 항목 | 적을 내용 |
|---|---|
| 사용한 데이터셋 | 실제로 불러와 사용한 데이터셋 이름 |
| 분석 목적 | 어떤 정보를 이용해 어떤 숫자를 예측하려 했는지 |
| 사용한 칼럼 | x와 y로 고른 원래 열을 모두 선택 |
| 분석 방법 | 모든 x 열과 y 열의 이름, 경사하강법으로 15회 학습한 내용 |
| 전처리 기록 | 처리함·처리 없음 선택. 처리했다면 열 이름과 방법을 기록 |

> [!KEY_POINT]
> x가 여러 개면 모두 적으세요. 전처리로 새 열을 만들었다면 그 이름도 분석 방법이나 전처리 기록에 씁니다. 하지 않은 전처리를 했다고 쓰지 마세요.
:::

:::page{type="concept" id="ch11-record-parameters" layout="basic"}
# 만든 식과 파라미터 값 남기기

카드의 **핵심 수치**에 15회 학습한 식과 파라미터의 실제 숫자를 적습니다. 기호만 쓰지 말고, 실행 결과에 나온 값을 확인하세요.

## 입력이 하나라면

$$
\hat{y}=ax+b
$$

- x가 어떤 열이고 y가 어떤 열인지 씁니다.
- 실제 숫자를 넣은 식과 **a, b 값**을 모두 적습니다.

## 입력이 여러 개라면

$$
\hat{y}=b+a_1x_1+a_2x_2+\cdots+a_nx_n
$$

- 각 x가 어떤 열인지 쓰고, 그 열에 곱하는 파라미터를 짝지어 적습니다.
- **모든 파라미터와 b**를 빠뜨리지 않습니다. 출력에서 다른 기호를 썼다면 그 표기를 사용해도 됩니다.

전처리한 값을 입력했다면 그 사실도 함께 적으세요. y도 바꾸었다면 예측값 역시 바뀐 값의 기준으로 나온다는 점을 표시합니다.

> [!TIP]
> 그래프 모양만 보고 숫자를 추측하지 마세요. 15회 학습한 뒤 출력된 식과 파라미터 값을 그대로 확인하여 기록합니다.
:::

:::page{type="practice-checklist" id="ch11-finish-card"}
# 그래프를 붙이고 카드 완성하기

**결과 근거**의 **출력에서 가져오기**로 자신이 만든 0~15회 학습 그래프를 붙입니다. 제공된 예시 이미지가 아닌 직접 실행한 그래프를 사용하세요.

**결과 해석**에는 0회와 15회를 비교하여 직선이나 손실값이 어떻게 달라졌는지 씁니다. 그래프에서 확인한 내용을 자기 말로 설명합니다.

- [ ] 실제 사용한 데이터셋 이름을 적었다.
- [ ] 입력한 x 열들을 모두 적고, 예측할 y 열을 구분했다.
- [ ] 전처리 여부와 처리한 열·방법을 기록했다.
- [ ] 15회 학습한 식과 모든 파라미터의 실제 값을 적었다.
- [ ] 0~15회 학습 과정 그래프를 붙였다.
- [ ] 그래프에서 달라진 점을 근거로 결과를 설명했다.

> [!TIP]
> 필수 항목과 위 내용을 확인했다면 **작성 완료**를 누르세요. 15회만으로 충분히 학습했다고 단정하지 말고, 더 살펴볼 점은 ‘한계와 추가 분석’에 짧게 남겨도 좋습니다.
:::
