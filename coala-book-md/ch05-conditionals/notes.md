# 5차시 강의 메모 (조건문)

- 대상: 대학 초급, 파이썬 GUI(Flet) 수업 5주차
- 지난 시간: 변수와 입력 칸(Field), 버튼
- 이번 시간 목표: if/else로 앱이 "판단"하게 만들기
- 흐름: 입력 → 판단 → 출력 (앞 시간 흐름과 연결)
- 예제 1: 나이 입력 → 20 이상이면 "성인" 아니면 "미성년자"
- 예제 2: BMI 값에 따라 저체중/정상/과체중 (elif)
- 실습: 알고플로에서 나이 판단 앱 만들기, 버튼 누르면 결과 Text에 표시
- 자주 하는 실수: 들여쓰기 빼먹기, = 와 == 헷갈림
- 이미지: 실습 화면 캡처 2장 쓸 예정 (앱 실행 전 / 결과 나온 후)
