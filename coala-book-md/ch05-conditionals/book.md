# 조건문
## 앱이 스스로 판단하게 만들기

### 학습 목표

- 조건에 따라 다른 결과를 보여 주는 코드를 설명할 수 있다.
- **if**, **else**, **elif**로 세 가지 이상의 경우를 나눌 수 있다.
- 알고플로에서 나이를 판단하는 앱을 만들 수 있다.

### 앱은 언제 판단할까?

지난 시간에 만든 앱은 입력 칸의 값을 그대로 보여 주기만 했습니다. 이번 시간에는 앱이 값을 보고 **판단**하게 만듭니다. 나이가 20 이상이면 "성인", 아니면 "미성년자"라고 답하는 것처럼, 같은 앱이 입력에 따라 다른 결과를 냅니다.
:::

:::page{type="concept" id="ch05-flow" layout="basic"}
# 입력 → 판단 → 출력

## 흐름에 판단이 들어간다

```flow
입력 | Field
판단 | if / else
출력 | Text
```

지난 시간의 흐름은 입력 → 처리 → 출력이었습니다. 이번에는 처리 자리에 **판단**이 들어갑니다. 판단은 질문 하나로 이루어집니다.

- 질문: "나이가 20 이상인가?"
- 답이 참이면 → 한쪽 결과를 보여 줍니다.
- 답이 거짓이면 → 다른 쪽 결과를 보여 줍니다.

> [!TIP]
> 판단의 질문은 항상 참 또는 거짓으로 답할 수 있어야 합니다. "나이가 많은가?"처럼 기준이 없는 질문은 코드로 옮길 수 없습니다.
:::

:::page{type="concept" id="ch05-if-else" layout="basic"}
# if와 else

## 두 갈래로 나누기

**if** 뒤에 질문을 적고, 참일 때 실행할 줄을 들여써서 적습니다. **else** 아래에는 거짓일 때 실행할 줄을 적습니다.

```python
age = 17

if age >= 20:
    print("성인입니다")
else:
    print("미성년자입니다")
```

```output
미성년자입니다
```

## 값을 바꾸면 결과가 바뀐다

같은 코드에서 **age**만 25로 바꾸면 다른 줄이 실행됩니다.

```python
age = 25

if age >= 20:
    print("성인입니다")
else:
    print("미성년자입니다")
```

```output
성인입니다
```

> [!KEY_POINT]
> **if**는 질문, 들여쓴 줄은 답이 참일 때 할 일, **else**는 답이 거짓일 때 할 일입니다. 두 줄 중 하나만 실행됩니다.
:::

:::page{type="concept" id="ch05-elif" layout="basic"}
# 세 갈래 이상 나누기

## elif로 경우 추가하기

경우가 셋 이상이면 **elif**를 사이에 넣습니다. 위에서부터 차례로 질문하고, 처음 참이 되는 곳의 줄만 실행합니다.

```python
bmi = 23.4

if bmi < 18.5:
    print("저체중")
elif bmi < 25:
    print("정상")
else:
    print("과체중")
```

```output
정상
```

- 첫 질문 "18.5보다 작은가?"는 거짓이라 지나갑니다.
- 둘째 질문 "25보다 작은가?"가 참이라 "정상"을 보여 줍니다.
- 그 아래 **else**는 실행되지 않습니다.
:::

:::page{type="comparison" id="ch05-mistakes"}
# 자주 하는 실수

조건문을 처음 쓸 때 가장 많이 나오는 실수 두 가지입니다.

| 실수 | 고치는 방법 |
|---|---|
| 들여쓰기를 빼먹는다 | **if** 아래 줄은 스페이스 네 칸을 띄운다 |
| **=** 와 **==** 를 헷갈린다 | 값을 넣을 때는 **=**, 같은지 물을 때는 **==** |
| **elif**를 **else if**로 적는다 | 파이썬은 **elif** 한 단어다 |

> [!TIP]
> 오류 문구에 "IndentationError"가 보이면 들여쓰기 문제입니다. 오류 줄 앞의 빈칸을 세어 보세요.
:::

# 나이 판단 앱 만들기

나이를 입력 칸에 적고 버튼을 누르면, 성인인지 미성년자인지 결과 Text에 보여 주는 앱을 만듭니다. 지난 시간의 입력 칸과 버튼에 판단 한 줄을 더하면 됩니다.

> [!TIP]
> 먼저 17을 넣어 "미성년자입니다"가 나오는지, 다음에 25를 넣어 "성인입니다"가 나오는지 두 번 확인하세요.
:::
