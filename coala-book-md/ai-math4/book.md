# 확률을 이용한 예측
## 데이터의 비율로 가능성 예상하기

### 학습 목표

- 데이터에서 사건이 일어난 비율을 구하고 확률 추정에 활용할 수 있다.
- 전체 데이터와 조건에 해당하는 데이터에서 구한 확률의 차이를 설명할 수 있다.
- AI를 활용하여 확률을 계산하고 간단한 예측 규칙을 만들 수 있다.
- 예측값과 실제 결과를 비교할 수 있다.

### 과거 기록으로 가능성 예상하기

내일 비가 올지 어떻게 예상할 수 있을까요? 지난 날들의 기록을 살펴보면 도움이 됩니다. 과거 기록에서 어떤 일이 얼마나 자주 일어났는지 알면, 비슷한 상황에서 그 일이 일어날 가능성을 예상할 수 있습니다.

이번 단원에서는 날씨 기록 데이터에서 비율을 구하고, 그 비율로 비가 올 가능성을 예측해 봅니다.
:::

:::page{type="concept" id="ch04-relative-frequency" layout="basic"}
# 데이터에서 구한 비율

## 사건이 일어난 비율 구하기

기록에서 어떤 사건이 일어난 횟수를 전체 관찰 횟수로 나눈 값을 **상대도수**라고 합니다.

**데이터에서 구한 사건의 상대도수 = 사건이 일어난 횟수 ÷ 전체 관찰 횟수**

이번 단원의 날씨 데이터는 100일의 기록입니다. 그중 비가 온 날은 32일입니다.

**비가 온 비율 = 32 ÷ 100 = 0.32 = 32%**

- 비가 온 날의 비율은 32%, 비가 오지 않은 날의 비율은 68%입니다.
- 우리는 이렇게 관찰된 비율을 이용하여 비가 올 확률을 **추정**합니다.
- 아무 조건 없이 이 기록만으로 결과를 하나 고른다면, 더 많이 나타난 **비가 오지 않음**을 고를 수 있습니다.

> [!KEY_POINT]
> 확률은 가능성을 나타냅니다. 비가 온 비율이 32%라고 해서 앞으로 반드시 비가 오지 않는 것은 아닙니다.
:::

:::page{type="concept" id="ch04-conditional" layout="basic"}
# 조건이 주어졌을 때의 확률

## 먹구름이 있다면 어떨까?

비가 올 가능성과, **먹구름이 있을 때** 비가 올 가능성은 같을까요? 조건이 생기면 살펴볼 기록이 달라집니다.

이번 데이터에서 먹구름이 있는 날은 40일이고, 그중 비가 온 날은 24일입니다.

**먹구름이 있을 때 비가 온 비율 = 24 ÷ 40 = 0.6 = 60%**

- 분모가 전체 100일에서 먹구름이 있는 **40일**로 바뀌었습니다.
- 조건에 해당하는 기록만 골라, 그 안에서 결과의 비율을 구합니다.
- 이렇게 조건이 주어졌을 때의 확률을 **조건부확률**이라고 합니다.

> [!KEY_POINT]
> 조건이 주어지면 비율을 계산하는 기준, 즉 분모가 바뀝니다. 전체가 아니라 조건에 해당하는 기록만 셉니다.
:::

:::page{type="comparison" id="ch04-compare-overall"}
# 전체와 조건을 비교하면

전체 기록에서는 비가 오지 않은 날이 더 많습니다. 하지만 먹구름이 있는 날만 보면 비가 온 날이 더 많습니다.

| 기준 | 기록 수 | 비가 온 비율 |
|---|---|---|
| 전체 | 100일 | 32% |
| 먹구름이 있는 날 | 40일 | 60% |

> [!TIP]
> 조건별 비율을 비교할 때는 그 비율이 몇 개의 기록으로 계산되었는지도 함께 확인하세요. 기록이 매우 적으면 비율이 우연에 크게 영향을 받을 수 있습니다.
:::

# 불러온 데이터 확인하기

## 데이터 불러오기 셀 실행하기

불러오기를 누르면 데이터를 불러오는 코드가 셀에 들어옵니다. 셀을 실행하고 아래에 나타나는 표에서 데이터의 앞부분을 확인합니다.

::image{src="assets/상위행확인.png" alt="데이터 불러오기 셀을 실행한 뒤 표시된 표. 먹구름, 높은 습도, 강한 바람, 비 열에 0 또는 1 값이 있고 행 번호 0부터 14까지 15행이 보인다" ratio="2.75" width="full" caption="데이터 앞부분 확인하기"}

- 먹구름, 높은 습도, 강한 바람, 비 네 개의 열이 있고, 모든 값은 0 또는 1입니다.
- 화면에는 앞부분 15행(행 번호 0부터 14)만 보이지만, 전체 데이터는 100행입니다.
- 한 행은 하루의 관찰 기록이며, 비어 있는 값은 없습니다.
- 불러온 표 데이터는 코드에서 **df**라는 이름으로 사용합니다. 이어지는 두 실습 모두 이 **df**를 그대로 사용합니다.
:::

:::page{type="comparison" id="ch04-columns"}
# 네 개의 열이 뜻하는 것

각 열의 값은 1 또는 0입니다. 1은 해당 조건이 있다는 뜻이고, 0은 없다는 뜻입니다.

| 열 이름 | 1의 의미 | 0의 의미 |
|---|---|---|
| 먹구름 | 먹구름 있음 | 먹구름 없음 |
| 높은 습도 | 높은 습도에 해당 | 높은 습도에 해당하지 않음 |
| 강한 바람 | 강한 바람 있음 | 강한 바람 없음 |
| 비 | 비가 옴 | 비가 오지 않음 |

> [!KEY_POINT]
> 먹구름, 높은 습도, 강한 바람은 예측에 사용할 **조건**입니다. 비는 예측한 뒤에 비교할 **실제 결과**입니다.
:::

:::page{type="practice-opening" id="ch04-practice-1" practice="004-1" practice-kind="확률 실습" platform="실습하기"}
# 전체 확률과 조건별 확률 비교하기

전체 데이터에서 비가 온 비율을 구하고, 먹구름, 높은 습도, 강한 바람이라는 조건이 주어졌을 때의 비율과 비교해 봅시다. AI에게 계산 코드를 요청한 뒤 주피터 노트북에서 실행합니다.

예시 프롬프트: "df의 먹구름, 높은 습도, 강한 바람, 비 열은 모두 0과 1이야. 전체에서 비가 1인 비율과 각 조건이 1일 때 비가 1인 비율을 계산해 줘. 계산에 사용한 기록 수, 그중 비가 온 기록 수, 비율을 표로 보여 줘. 주피터 노트북에서 실행할 코드를 만들어 줘."

> [!TIP]
> 세 조건은 각각 따로 비교합니다. 조건을 합치거나 비율을 곱하지 않습니다. 계산에는 미리보기 행이 아니라 전체 100행을 사용합니다.

- [ ] 전체 기록에서 비가 온 비율을 계산할 수 있다.
- [ ] 각 조건이 1인 기록에서 비가 온 비율을 계산할 수 있다.
- [ ] 조건에 따라 계산의 분모가 달라지는 이유를 설명할 수 있다.
:::

:::page{type="concept" id="ch04-practice-1-flow" layout="basic"}
# 실습 004-1 진행과 결과 확인

## 활동 흐름

1. 불러온 데이터의 열과 0, 1의 의미를 확인합니다.
2. AI에게 확률 계산 코드를 요청합니다.
3. 생성된 코드를 실행합니다.
4. 전체 확률과 조건별 확률을 비교합니다.

## 결과를 보고 답해 봅시다

- 전체에서 비가 온 비율은 얼마인가요?
- 각 조건에서 확률을 계산할 때 분모는 무엇인가요?
- 어떤 조건에서 비가 온 비율이 가장 높나요?
- 조건이 있을 때의 비율은 전체 비율과 어떻게 다른가요?
:::

:::page{type="comparison" id="ch04-practice-1-result"}
# 실행 결과와 비교해 봅시다

실행 결과가 아래 표와 같은지 확인해 봅시다. 비율은 비가 온 기록 수를 해당 기록 수로 나눈 값입니다.

| 기준 | 비가 온 기록 수 / 해당 기록 수 | 비가 온 비율 |
|---|---|---|
| 전체 | 32 / 100 | 32% |
| 먹구름 = 1 | 24 / 40 | 60% |
| 높은 습도 = 1 | 21 / 40 | 52.5% |
| 강한 바람 = 1 | 16 / 35 | 약 45.7% |

> [!KEY_POINT]
> 조건마다 분모가 다릅니다. 전체는 100일, 먹구름은 40일, 높은 습도는 40일, 강한 바람은 35일을 기준으로 비율을 구했습니다.
:::

:::page{type="practice-opening" id="ch04-practice-2" practice="004-2" practice-kind="예측 실습" platform="실습하기"}
# 예측 규칙을 만들고 실제 결과와 비교하기

먹구름이 있는 날은 비가 온 비율이 60%로 절반보다 높았습니다. 이 결과를 바탕으로 먹구름이 1이면 비를 1로, 0이면 비를 0으로 예측하는 간단한 규칙을 만들고, 실제 비 열과 비교해 봅시다.

예시 프롬프트: "df에서 먹구름이 1이면 비를 1로, 먹구름이 0이면 비를 0으로 예측해 줘. 예측값과 실제 비 값을 비교해서 네 가지 조합별 개수를 표로 보여 줘. 표의 행은 실제 결과, 열은 예측 결과로 해 줘. 주피터 노트북에서 실행할 코드를 만들어 줘."

> [!TIP]
> 예측값은 먹구름 열로만 만듭니다. 실제 비 열을 보고 예측값을 정하지 않습니다.

- [ ] 조건을 이용하여 간단한 예측값을 만들 수 있다.
- [ ] 예측값과 실제 결과를 비교할 수 있다.
- [ ] 잘못 경고한 경우와 비를 놓친 경우를 구분할 수 있다.
:::

:::page{type="concept" id="ch04-practice-2-flow" layout="basic"}
# 실습 004-2 진행하기

## 규칙의 이유

먹구름이 있는 날은 40일 중 24일에 비가 와서 60%였습니다. 먹구름이 없는 날은 60일 중 8일만 비가 와서 약 13.3%였습니다. 그래서 먹구름이 1이면 비가 온다고(예측값 1), 0이면 비가 오지 않는다고(예측값 0) 예측합니다.

## 활동 흐름

1. 먹구름으로 예측값을 만듭니다.
2. 예측값을 실제 비 값과 비교합니다.
3. 네 가지 경우의 개수를 확인합니다.
4. 예측이 맞은 경우와 두 종류의 실수를 구분합니다.
:::

:::page{type="concept" id="ch04-practice-2-check" layout="basic"}
# 실습 004-2 결과 확인

## 결과를 보고 답해 봅시다

- 비가 온다고 예측했지만 실제로 오지 않은 날은 몇 일인가요?
- 비가 오지 않는다고 예측했지만 실제로 온 날은 몇 일인가요?
- 두 경우는 어떤 점에서 다른 실수인가요?
- 우산을 준비하는 상황에서는 어떤 실수를 줄이고 싶은가요?

> [!KEY_POINT]
> 같은 기록으로 규칙을 정하고 결과를 비교했으므로, 이 결과가 앞으로의 새로운 날에서도 같은 예측 성능을 보장하지는 않습니다.
:::

:::page{type="comparison" id="ch04-practice-2-result"}
# 예측과 실제 결과 비교 표

행은 실제 결과, 열은 예측 결과입니다. 예측값과 실제 비 값은 다를 수 있습니다.

| 실제 결과 | 비가 온다고 예측(1) | 비가 안 온다고 예측(0) |
|---|---|---|
| 실제 비 옴(1) | 24일: 비를 맞게 예측 | 8일: 비를 놓침 |
| 실제 비 안 옴(0) | 16일: 잘못 경고 | 52일: 비가 안 오는 것을 맞게 예측 |

> [!TIP]
> 잘못 경고한 16일과 비를 놓친 8일은 서로 다른 실수입니다. 우산을 괜히 챙긴 날과 우산 없이 비를 맞은 날을 떠올려 보세요.
:::

:::page{type="concept" id="ch04-precision-recall" layout="basic"}
# 추가로 알아보기: 정밀도와 재현율

## 비 오는 날을 얼마나 잘 찾아냈을까?

이번 활동에서 찾아내려는 결과는 **비가 오는 날**입니다. 앞의 비교 표를 두 가지 기준으로 다시 읽어 봅시다.

::image{src="assets/정밀도와 재현율 비교 인포그래픽.png" alt="비 예측으로 이해하는 정밀도와 재현율 인포그래픽. 행은 실제로 비 옴과 비 안 옴, 열은 비 온다고 예측과 비 안 온다고 예측이며, 파란 세로 영역이 정밀도, 초록 가로 영역이 재현율의 기준을 나타낸다" ratio="1.5" width="full"}

- **정밀도(Precision):** 비가 온다고 예측한 날(파란 세로 영역) 중 실제로 비가 온 날의 비율입니다. 이번 결과는 **24 ÷ 40 = 60%**입니다.
- **재현율(Recall):** 실제로 비가 온 날(초록 가로 영역) 중 예측으로 찾아낸 날의 비율입니다. 이번 결과는 **24 ÷ 32 = 75%**입니다.

> [!KEY_POINT]
> 맞게 예측한 비 오는 날 수는 같지만, 기준이 되는 전체가 다릅니다.
:::
