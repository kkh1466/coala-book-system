# 바이브 코딩
## 말로 설명하고 프로그램으로 만들기

### 학습 목표

- 바이브 코딩의 의미를 설명할 수 있다.
- AI에게 원하는 프로그램을 요청할 수 있다.
- AI가 만든 코드를 주피터 노트북에서 실행할 수 있다.
- 실행 결과를 확인하고 간단한 수정을 요청할 수 있다.

### 바이브 코딩이란?

프로그램을 만들려면 코드를 한 줄씩 직접 써야 한다고 생각하기 쉽습니다. 하지만 이제는 다른 방법이 있습니다.

**바이브 코딩(Vibe Coding)**은 만들고 싶은 프로그램을 말로 설명하고, AI가 작성한 코드를 실행하며 고쳐 가는 방식입니다.
:::

:::page{type="concept" id="ch02-prompt-to-code" layout="basic"}
# 프롬프트로 프로그램 요청하기

## 1단원의 프롬프트를 떠올려 봅시다

1단원에서 우리는 AI에게 원하는 것을 구체적으로 적은 **프롬프트**를 보내면 더 좋은 답을 받을 수 있다는 것을 배웠습니다.

지금까지 AI에게 요청한 것은 설명과 답변이었습니다. 이제는 한 가지를 더 요청할 수 있습니다. 바로 **프로그램 코드**입니다.

## 바이브 코딩의 흐름

- 만들고 싶은 프로그램을 말로 설명합니다.
- AI가 코드를 작성합니다.
- 코드를 실행하고 결과를 확인합니다.
- 아쉬운 부분이 있으면 다시 말로 수정을 요청합니다.

> [!KEY_POINT]
> 바이브 코딩에서도 좋은 프롬프트가 중요합니다. 무엇을 입력받고, 무엇을 보여 줄지 분명하게 적을수록 원하는 프로그램에 가까워집니다.
:::

:::page{type="comparison" id="ch02-roles"}
# 사람과 AI의 역할

바이브 코딩에서는 사람과 AI가 할 일을 나누어 맡습니다.

| 사람이 하는 일 | AI가 하는 일 |
|---|---|
| 원하는 기능 설명하기 | 코드 작성하기 |
| 코드 실행하고 결과 확인하기 | 요청에 따라 코드 수정하기 |

> [!KEY_POINT]
> AI가 만든 프로그램도 결과를 반드시 확인해야 합니다. 실행해서 원하는 대로 동작하는지 보는 것은 사람의 몫입니다.
:::

:::page{type="concept" id="ch02-jupyter" layout="basic"}
# 주피터 노트북 살펴보기

## 코드를 입력하고 바로 결과를 보는 곳

**주피터 노트북(Jupyter Notebook)**은 코드를 입력하고 실행 결과를 바로 확인하는 환경입니다. 이번 단원의 실습은 모두 여기에서 진행합니다.

::image{src="assets/ipynb 소개.png" alt="주피터 노트북 화면. 왼쪽의 실행 버튼, 가운데의 셀, 아래의 셀 추가 버튼, 오른쪽 위의 AI Chat 버튼이 표시되어 있다" ratio="2.15" width="full" caption="주피터 노트북 화면"}

- **셀(cell):** 코드를 적는 칸입니다. 셀 하나에 코드를 적고 실행합니다.
- **실행 버튼:** 셀 왼쪽에 있습니다. 누르면 그 셀의 코드가 실행됩니다.
- **셀 추가:** 셀 아래의 **코드** 버튼을 누르면 새 셀이 생깁니다.
- **AI 채팅:** 셀 오른쪽 위의 **AI Chat** 버튼을 누르면 AI에게 코드를 요청하는 창이 열립니다.
:::

:::page{type="concept" id="ch02-ask-ai" layout="basic"}
# AI에게 프로그램 요청하기

## AI Chat 창에 원하는 프로그램 적기

**AI Chat** 버튼을 누르면 오른쪽에 대화 창이 열립니다. 아래 입력 칸에 만들고 싶은 프로그램을 설명하고 **전송** 버튼을 누릅니다.

::image{src="assets/프롬프트입력.png" alt="AI Chat 창. 아래 입력 칸에 주사위를 굴려 1부터 6까지 숫자 하나를 무작위로 출력하는 파이썬 코드를 만들어 달라는 프롬프트가 적혀 있고, 오른쪽 아래에 전송 버튼이 있다" ratio="0.66" width="half" caption="AI Chat 창에 프롬프트 입력하기"}

예시에서는 "주사위를 굴려 1부터 6까지 숫자 하나를 무작위로 출력하는 파이썬 코드를 만들어줘."라고 요청했습니다. 무엇을 하는 프로그램인지 한 문장으로 분명하게 적었습니다.
:::

:::page{type="concept" id="ch02-add-code" layout="basic"}
# 코드를 셀에 넣기

## AI가 만든 코드 확인하기

전송하면 AI가 요청에 맞는 코드를 만들어 보여 줍니다. 코드 아래의 **현재 셀에 추가** 버튼을 누르면 그 코드가 선택한 셀에 들어갑니다.

::image{src="assets/입력후.png" alt="AI Chat 창에 주사위 프로그램 코드가 두 줄 나타나 있고, 코드 아래의 현재 셀에 추가 버튼을 가리키는 화살표가 있다" ratio="0.66" width="half" caption="현재 셀에 추가 버튼 누르기"}

> [!TIP]
> 코드를 넣기 전에 코드가 들어갈 셀을 먼저 선택해 두세요. 코드는 선택한 셀에 추가됩니다.
:::

:::page{type="concept" id="ch02-run" layout="basic"}
# 실행하고 결과 확인하기

## 실행 버튼을 눌러 결과 보기

셀에 코드가 들어오면 셀 왼쪽의 **실행 버튼**을 누릅니다. 실행 결과는 셀 바로 아래에 나타납니다.

::image{src="assets/실행및 결과확인.png" alt="주사위 코드가 들어간 셀과 왼쪽의 실행 버튼, 셀 아래에 표시된 실행 결과 1. 오른쪽에는 AI Chat 창이 열려 있다" ratio="2.2" width="full" caption="실행 버튼을 누르고 결과 확인하기"}

- 예시에서는 주사위를 굴린 결과로 **1**이 나왔습니다.
- 다시 실행하면 1부터 6 사이의 다른 숫자가 나올 수 있습니다.
- 결과가 요청한 것과 다르면 AI Chat 창에서 바꾸고 싶은 점을 다시 요청합니다.

> [!KEY_POINT]
> 요청하기, 코드 넣기, 실행하기, 결과 확인하기. 이 네 단계가 바이브 코딩의 기본 과정입니다.
:::

# 나를 소개하는 프로그램

AI에게 별명, 좋아하는 과목, 취미를 입력받아 소개 문장을 출력하는 프로그램을 요청하고, 주피터 노트북에서 실행해 봅시다. 선생님과 함께 한 단계씩 따라 합니다.

예시 프롬프트: "주피터 노트북에서 별명, 좋아하는 과목, 취미를 입력받아 소개 문장을 출력하는 간단한 파이썬 프로그램을 만들어 줘. 추가 설치 없이 코드 셀 하나에서 실행되게 해 줘."

> [!TIP]
> 프로그램에 입력할 때는 실제 이름 대신 별명을 사용하세요.

- [ ] AI에게 간단한 프로그램을 요청할 수 있다.
- [ ] 생성된 코드를 입력하고 실행할 수 있다.
- [ ] 입력한 내용이 결과에 반영되는지 확인할 수 있다.
:::

:::page{type="practice-opening" id="ch02-practice-2" practice="002-2" practice-kind="바이브 코딩 실습" platform="실습하기"}
# 공부 시간 계산기

전체 공부 시간과 과목 수를 입력하면, 과목마다 공부할 시간을 똑같이 나누어 계산하는 프로그램을 만듭니다. 실습 002-1에서 경험한 방법을 활용하여 직접 진행해 봅시다.

예시 프롬프트: "주피터 노트북에서 전체 공부 시간(분)과 과목 수를 입력받아 과목마다 공부할 시간을 계산하는 간단한 파이썬 프로그램을 만들어 줘. 추가 설치 없이 코드 셀 하나에서 실행되게 해 줘."

> [!TIP]
> 전체 공부 시간 120분, 과목 수 3개를 입력했을 때 과목당 40분이 나오는지 확인하세요.

- [ ] 필요한 기능을 프롬프트로 작성할 수 있다.
- [ ] 프로그램을 실행하고 계산 결과를 확인할 수 있다.
- [ ] 결과의 표현을 바꾸도록 요청할 수 있다.
:::

:::page{type="concept" id="ch02-revise" layout="basic"}
# 결과 표현 바꾸기

## 간단한 수정 요청하기

계산 결과가 맞게 나왔다면, 이번에는 결과를 보여 주는 방식을 바꿔 봅시다. 코드를 직접 고치지 않아도 됩니다. AI Chat 창에 바꾸고 싶은 점을 말로 요청하면 AI가 코드를 수정해 줍니다.

수정 요청 예시: "결과에 '과목마다 ○○분씩 공부하면 됩니다.'라는 안내 문장을 넣어 줘."

- 수정된 코드를 다시 셀에 넣고 실행합니다.
- 120분과 3개를 다시 입력해서 안내 문장이 나오는지 확인합니다.

> [!TIP]
> 수정 요청도 프롬프트입니다. 바꾸고 싶은 부분만 짧고 분명하게 적으면 됩니다.
:::
