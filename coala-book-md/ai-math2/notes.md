## 설명할 내용

### 바이브 코딩이란?

만들고 싶은 프로그램을 말로 설명하고, AI가 작성한 코드를 실행하며 수정해 가는 방식이라고 설명해 주세요.

### 사람과 AI의 역할

간단한 표로 정리해 주세요.

- 사람: 원하는 기능 설명하기, 실행하기, 결과 확인하기
- AI: 코드 작성하기, 요청에 따라 코드 수정하기

AI가 만든 프로그램도 결과를 확인해야 한다는 점을 핵심정리로 제시해 주세요.

### 주피터 노트북에서 실행하기

1. **ipynb 소개.png**: 주피터 노트북 화면 소개
2. **프롬프트입력.png**: AI에게 프로그램 요청하기
3. **입력후.png**: 요청 후 코드 입력으로 이어지는 과정
4. **실행및 결과확인.png**: 코드 실행과 결과 확인

## 실습 002-2: 공부 시간 계산기

첫 실습에서 경험한 방법을 활용하여 직접 진행하는 실습으로 구성해 주세요.

**실습 내용**

전체 공부 시간과 과목 수를 입력하면, 과목마다 공부할 시간을 똑같이 나누어 계산하는 프로그램을 만듭니다.

**예시 프롬프트**

“주피터 노트북에서 전체 공부 시간(분)과 과목 수를 입력받아 과목마다 공부할 시간을 계산하는 간단한 파이썬 프로그램을 만들어 줘. 추가 설치 없이 코드 셀 하나에서 실행되게 해 줘.”

전체 공부 시간 120분, 과목 수 3개를 입력했을 때 과목당 40분이 나오는지 확인하도록 안내해 주세요.

**간단한 수정 요청 예시**

“결과에 ‘과목마다 ○○분씩 공부하면 됩니다.’라는 안내 문장을 넣어 줘.”

**실습 목표**

- 필요한 기능을 프롬프트로 작성할 수 있다.
- 프로그램을 실행하고 계산 결과를 확인할 수 있다.
- 결과의 표현을 바꾸도록 요청할 수 있다.
